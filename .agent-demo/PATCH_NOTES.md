# 试玩改版补丁说明（2025 第二轮试玩反馈 → 8 项体验修复）

本目录是**补丁镜像**，不改动原型本身。双击 `apply_updates.cmd` 会把
`prototype\scripts` 与 `prototype\data` 覆盖到仓库根目录的 `prototype\` 下。

改动文件：

- `prototype/scripts/scene_hotspot.gd` — 热区新增 `draw_frame` 开关（关掉后只留点击热区与悬停提示，不画框）。
- `prototype/scripts/chapter_main.gd` — 场景标题/人物名/器物名标签改为鼠标穿透（不挡下层热区点击）；物品弹窗按钮“主动复核这件物品”改为“查看实物 · 形成私人判断”。
- `prototype/scripts/immersive_core.gd` — 茶馆/拜访拆分数据逻辑、返回店铺时清空柜台选中物件、剧情人物判断、寒暄台词读取、茶馆传闻读取、visit_origin 存档。
- `prototype/scripts/immersive_main.gd` — 热区置低图层、交谈打开时隐藏热区框、柜台改为托盘热区、心声卡片提到最高非遮挡层、市场店招式按钮、目的地图文卡片、新手提问 chips、对话注入当前物件上下文、自由输入按货名自动换看货对象、茶馆/拜访/夜间三场景拆分、点击式剧情选择按钮、移除“器物与判断”笔记页。
- `prototype/data/immersive_content.json` — 新增 `teahouse_schedule`（每晚谁在茶馆）、`teahouse_events`（茶馆传闻）、`visit_lines`（无剧情拜访的固定对白）。

## 逐条对应

1. **图层与遮挡**：所有亮框热区移到背景之上、人物/物品/文字之下；柜台热区从整块大矩形缩成托盘区域（0.55,0.63,0.42,0.27），提示语改为“台面托盘 · 查看当前物件”；**打开交谈面板时热区框全部隐藏**（场景当背景，只看人物与柜台物件），收起交谈后恢复可点击区域。人物名/物品名不再被框压住。
2. **目的地按钮图文化**：出门面板改为 4 张“场景截图卡片”（市场/拍卖/茶馆/店门），图内嵌短标题与一句话说明。⚠️ 本环境没有图像生成工具与外部生图接口，暂时用现有场景美术裁切 + 数据化 region（`_destination_card` 已留好换图位：换新 PNG 只需替换 texture/region）。有可用的生图服务后我可以批量生成正式卡片图。
3. **市场去边框**：所有店铺/摊位不再画金色描边（`draw_frame=false`），只保留金字店招；店招悬停时描金高亮，点击/多边形热区仍然有效，悬停仍显示主营与推荐货品。
4. **查看物品与心声层级**：弹窗按钮更名“查看实物 · 形成私人判断”；心声卡片 `z_index=30` 提到商品网格之上且鼠标穿透，不再被挡、不挡点击。
5. **对话上下文与新手引导**：每次 LLM 请求都附上“当前正在看的物件《X》（类别Y）+ 若提到别的物件请先确认是哪一件”的约束；自由输入里提到店里另一件货名时会**自动把该货拿到近处**再继续对话，避免答错对象。卖家/买家对话区新增“可以这样问”快捷 chips（问来历/品相/心理价/来意；问需求/用途/预算/年代），点击即发出整句，不用从头学怎么打字。
6. **茶馆与拜访拆分**：数据表 `teahouse_schedule` 决定每晚谁在茶馆（按日轮换，占位值可改）；茶馆只列在场者并显示当日“茶座传闻”特殊事件；不在茶馆的人进“拜访”列表。有剧情线的人→点击式“正事”选择按钮直接推进剧情节点（仍可自由闲聊）；无剧情线的人→读取 `visit_lines` 一段固定对白后即结束拜访，不再硬凑大模型对话。目前 5 位夜谈角色都绑有剧情节点，所以“无剧情寒暄”路径会在未来新增普通街坊时生效，机制与文案已备好。
7. **柜台物件状态泄漏**：`travel("shop")` 现在会清空 `selected_item_id`——给 NPC 看过的东西回店后会放回货架，不再自己出现在柜台上。
8. **笔记页清理**：删除“器物与判断”时间线页；私人判断只保留在对应器物的详情弹窗里查看。

## 需要你本地做

1. 双击 `.agent-demo\apply_updates.cmd` 应用补丁。
2. 双击 `prototype\运行测试.cmd` 跑八组回归（本会话被一个演示用 Task Contract 限制 shell，只允许 `git status`，我无法在此执行 Godot/测试命令，未跑验证）。
3. 打开 `prototype\project.godot` 试玩确认观感（图层、卡片裁切区域可能需按实际分辨率微调 Rect 数值）。

## 已知偏差 / 待定

- 目的地按钮暂用美术裁切而非 AI 生图（见第 2 条）。
- 茶馆排班/传闻为占位数据，可随时改 `immersive_content.json`。
- “说话前后矛盾”只靠提示词约束缓解；更强的角色一致性（记忆摘要/人格卡）建议在 docs 定稿后做，避免在原型里偷偷造永久规则。
- 剧情文案打磨未纳入本次代码改动。
