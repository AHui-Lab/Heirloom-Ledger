# 主店 2.5D 素材

本目录保存主店分层场景的新版本素材。旧版 `shop-v2.png`、人物图集与器物图集继续保留，便于回退。

- `shop-master-v4.png`：统一透视与光照的构图参考。
- `shop-background-v4.png`：不含人物与前景柜台的后景。
- `shop-counter-foreground-v4-alpha.png`：独立透明柜台前景，用于稳定遮挡人物下缘。
- `display-mat-v4-alpha.png`：当前器物的固定展示托垫。
- `portrait-*-v4-alpha.png`：赵庆生、林若岚、孙玉梅、吴致远、周伯安、许闻溪、何景明、陈素琴八名角色的独立透明立绘。

运行时层级固定为：后景 `0` → 热点 `2` → 人物 `10` → 柜台前景 `12` → 托垫 `13` → 器物 `14` → 姓名、提示与对话 `18+`。`source`、`extracted` 与未带 `alpha` 的文件是生成和清理过程留档，不应直接被场景引用。
