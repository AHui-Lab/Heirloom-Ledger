# TASK-STORY-003

## Goal

依用户要求，以原创高价值藏品与虚构南迁往事构建有明确开端、发展、高潮、结局的全篇故事，将人物、主线任务、支线任务、证据和长期后果连成可审阅的策划方案。

## Acceptance Criteria

- [x] 核心藏品的艺术、稀缺、历史与利益价值有具体依据，不能仅以高报价代替冲突。
- [x] 后台真相、代际时间线、物件流转与人物知情相互一致。
- [x] 六章形成完整因果，各章有行动目标、转折和阶段结果。
- [x] 既有八名 NPC 与新增核心人物均有任务联系、独立诉求及结尾去向。
- [x] 至少 24 个主线任务和 12 个支线任务有 ID、前置、行动、选择、结果与回响。
- [x] 有可核验的任务依赖图、关键证据替代路径、拒绝/暂缓/失败路线。
- [x] 结局有前提与代价，不能用最后一题覆盖玩家此前的选择。
- [x] 标明虚构范围及旧版退居备选；不改 locked 规则或游戏实现。
- [x] 文档可从 Obsidian 总入口进入；完成一致性与链接检查并报告结果。
