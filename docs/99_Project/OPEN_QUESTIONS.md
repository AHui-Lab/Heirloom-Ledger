# Open Questions
以下问题尚未确定，不得被 Agent 擅自实现为永久规则：
- X City 的正式名称是什么？
- 5 人营业日采用 2/3 或 3/2 的具体选择权重是什么，重要剧情例外最多可以额外增加多少来客，这些参数是否随章节进度变化？
- 哪些剧情或经营主题允许连续出现 3 名同类客人，这种例外在同一章节中最多出现多频繁，是否还需要限制器物类别或交易难度的连续重复？
- 一个章节允许连续多少个纯经营日，以及每个章节至少需要多少个重要剧情节点，才能避免叙事停滞而不形成“每日剧情打卡”？
- 判断挑战强度如何随章节成长，以及同类挑战需要怎样限制连续重复？
- 判断挑战的首批类型库、每类挑战的最小有效线索标准，以及知识、经验、提问和观察条件怎样控制线索可得性？
- V1 首批需要哪些经营主题？世界来源与玩家来源应按什么比例选择，多个来源如何组合，多久可以重复，对来客与案件候选权重影响多大，玩家能够获得多明确的提示？
- 普通公开交易信号需要累计到什么门槛、是否以及如何衰减、怎样按类别与价格层级分别记录，同一来源可以叠加到什么程度，以及口碑带来的机会与风险应保持怎样的比例？
- “尚无名气、偶有人提起、逐渐形成口碑、在相关圈子里受到认可”四档分别对应怎样的内部阈值，普通交易与重大事件最多可以推动多少，阶段下降时如何反馈？
- “声誉受损、尚无定论、口碑稳定、值得信赖”四档全局信誉分别对应怎样的内部阈值，初始处于哪一档，哪些行为使其上升、下降或恢复，各阶段如何影响来客与交易态度？
- “防备、生疏、熟悉、信任、深交”五档 NPC 关系分别对应怎样的内部阈值，NPC 初始处于哪一档，哪些行为使关系上升或下降，重大事件最多跨越多少阶段？
- NPC 关系阶段、具体记忆、承诺、利益冲突和社会连接共同影响行为时，采用怎样的条件优先级，哪些帮助即使处于“深交”也不能无条件提供？
- 哪些事件只影响类别口碑、全局信誉或 NPC 关系中的一项，哪些传播条件允许同一事件影响多项，各维度又分别怎样影响来客生成和交易行为？
- 哪些 NPC 属于能够立即形成主题候选的重要 NPC，高价值交易如何相对于玩家当前经营层级判定，重大事件需要达到什么传播条件？
- Post-V1 是否重新引入连续时间、预约、耗时店内活动、中断恢复、外出、拍卖和正式学习；如果引入，应采用怎样的时间与日程模型？这些问题不阻塞 V1 Core Loop。
- 是否存在明确失败条件？
- 是否存在最终结局？
- NPC 是否需要独立 Agent？
- 古玩的市场价格系统如何变化？
- 鉴定概率公式如何设计？
- 玩家知识体系需要细分到什么程度？
- 主线与动态故事的比例是多少？
- 游戏最终使用什么引擎？
- LLM 调用采用云 API 还是支持玩家 BYOK？
- 古玩具体数据结构如何定义？
- 关系、信任、记忆和社会连接的数值/规则如何运作？
- World State 的 schema、持久化方式和事件状态机如何设计？
- 什么样的新信息构成会触发鉴定更新的“有意义的新线索”？
- 哪些器物瑕疵足以形成明确判假，每种瑕疵需要什么经验才能识别？
- 已售假货在二次倒卖或被他人看货时，具体如何判定为“被真实发现”？
- 假货被发现后，信誉损失、口碑传播和知识/经验收益如何确定？
- 基础鉴定委托的资金与库存触发阈值、保证出现的时间范围、最低服务费和额外收益如何确定？
- 章节化营业结构下，基础鉴定委托应通过次数、触发条件、收益上限还是其他规则防止被反复刷取？原定时间或日程成本不再适用于 V1。
- 未来应采用哪些更贴近现实古玩经营的方式扩展或替代基础鉴定委托安全网？
- 卖货客人的认知状态、表达诚实度、出售动机和谈判策略分别需要哪些具体枚举与组合限制？
- 玩家可以通过哪些公平但不直接泄露隐藏标签的对话线索判断卖货客人的状态？
- 日常随机客人与重要 NPC 是否共用同一套隐藏状态模型？
- 买货客人的购买目的、专业程度、预算弹性、购买急迫度和谈判策略分别需要哪些具体枚举与组合限制？
- 买家初次至少需要公开哪些宽泛需求，才能让玩家合理开始推荐？
- 类别、约略价格和年代与库存的匹配规则、模糊范围和排序方式是什么？
- 古玩类别的父类、子类和同级关系如何定义？
- 年代范围的具体边界与“部分接近或相邻”的判定如何定义？
- 玩家提出报价后，报价与买家预算的模糊匹配如何反馈？
- 没有完全匹配时，弱匹配候选具体保留哪些组合、最多显示多少件，以及推荐弱匹配是否额外消耗买家耐心？
- 玩家对年代、来源、真伪等客观属性作出错误陈述后，除“原买家二次转卖时请懂行买家看货”这一标准范例外，还需要哪些后续发现方式？三个发现者层级各自能发现哪些问题，以及如何根据三档问题严重程度、假货成交价格、三档买家身份、交易关系和传播范围确定无影响、轻度或重度发酵及具体信誉/关系/事件后果？第一版交易当下不强行区分误判与故意欺骗；价格表达不纳入这一项的自动判定。三档严重程度的 V1 基本边界已由 DEC-017 确认，后续只需处理复杂边界案例。
- 同一问题在同一传播圈层中再次被发现时，具体如何记录；当后续发现进入新的传播圈层、涉及新的关系对象或满足新的事件条件时，新增影响的上限和合并方式是什么？
- 个人关系圈、行业圈、公众/市场圈的具体边界、触发事件发生概率、传播速度、事件间隔和每层对应的具体后果是什么？不同主要干预的可用事件窗口、成功率计算和失败后果如何确定？
- V1 中每个传播圈层的一次主要干预应付出什么明确代价？章节化营业不再使用时间或日程成本，代价可以来自机会、关系、资金、信息暴露或其他事件条件，但尚未确定。
- 最终选择阶段中，哪些玩家行为属于必要的最后议价，哪些属于继续推荐、拖延或施压并可能导致买家离店？
- 交谈耐心需要多少个模糊态度阶段，各阶段如何命名和表现？
- 对话行为需要哪些完整分类，各分类具体消耗多少耐心？
- 一次性耐心挽回在什么条件下可用、恢复多少，以及哪些 NPC 会接受？
- 最终报价阶段中，哪些玩家行为属于必要议价，哪些属于继续拖延并可能导致 NPC 离店？
