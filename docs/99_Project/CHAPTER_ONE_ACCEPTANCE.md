## Deviations / Known Issues

- 遵守“暂不付费联调”。所有自动网络测试连接127.0.0.1；用户后续手动连接产生的费用由其服务商计费。模型的真实角色稳定性、语气和延迟尚未实测，不将其标成已通过。
- 美术为内置imagegen生成的店铺、8人物图集与24物件图集。店外独立背景两次因生成服务网络错误失败，当前使用物件/专家插画的交互面板；人物为单立绘，无多表情图集。
- 年代与粗略估价尚是宽区间原型；不同器物、角色和价格的平衡需要玩家试玩。图像不是可据以鉴定的精确3D模型。
- 自由输入不是任意语义都能结算。Core保留有限意图路由；明确按钮为可靠交易入口，LLM没有权威写状态能力。
- 店外为两件摊货、两件竞拍拍品及专家拜访的有限第一章机会，不会反复进出刷新。
- 角色有各自往来记忆和关系变化，但没有后台自由行动的完整社会模拟。剧情选择的短文本采用已写好的章节内容，不依赖LLM编造事实。

## 玩家验收顺序

1. 用自己的配置开始第一章，先看开场是否始终是来客口吻；观察/鉴定是否显示为未出口内心。
2. 推荐物件并用事实卡回答一次，试一次报价和拒绝；若报错，带HTTP/诊断元数据反馈，勿提供Key。
3. 午间试古玩街/专家，第三日后试拍卖；保存退出再继续。
4. 连续经营并查旧账，观察角色记忆、风险反馈和最终收束；反馈按Bug / Design / Balance / UX / LLM / Content分类。

本轮重点让玩家知道：怎样开始、怎样回答、怎样承担结果，并能把一整章玩完。下一轮根据真实试玩修正，不因为测试通过就锁定全部设计。
