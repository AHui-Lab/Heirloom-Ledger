# Idea Inbox

本文件记录尚未进入当前版本核心规则的未来玩法想法。Idea 不等于 Design Decision，不得被实现 Agent 当作当前版本需求。

## IDEA-001：以藏品抵押或抵换收购物品

**Idea:** 当玩家现金不足但希望收购物品时，可以提出以现有藏品作为抵押、抵换或交易条件。

**Potential Value:** 增加库存管理、现金流和谈判策略，也更贴近现实古玩交易。

**Current Scope:** 不进入第一版。第一版仅支持现金交易和压价；最终成交价超过玩家当前资金时，交易不能完成。

**Needs Design:** 抵押与所有权规则、NPC 接受条件、估值、赎回、欺诈风险、关系影响及失败后果。

## IDEA-002：主动推销非目标库存

**Idea:** 在与买货客人的对话中，玩家可以推荐不完全符合客人原始目标、但自己希望尽快出售的库存，例如刚收购的物件或需要回笼现金的滞销物件。

**Potential Value:** 增加主动销售、库存周转和对 NPC 偏好的判断空间。

**Current Scope:** 暂不进入第一版核心规则。第一版允许玩家在没有完全匹配时，从系统保留的相关弱匹配中自行选择并主动推销，但本 Idea 所指的是明显偏离买家公开目标的主动推销，仍不属于第一版常规推荐。

**Needs Design:** 可偏离需求的程度、NPC 接受概率、对话反馈、议价影响、信誉风险及是否可能造成反感。

## IDEA-003：现实化经营恢复方式

**Idea:** 在基础鉴定委托之外，结合现实古玩经营加入寄售、代卖、赊账、熟人援助或其他无需立即投入完整本金的恢复方式。

**Potential Value:** 让经营失败后的恢复更贴近行业现实，并形成关系、人情、信用和分成等新的选择与后果。

**Current Scope:** 不进入当前 V1 核心规则。V1 暂时使用基础鉴定委托作为防止经营循环永久中断的安全网。

**Needs Design:** 各恢复方式的现实依据、解锁条件、NPC 关系要求、费用或分成、违约风险、是否可能被重复利用，以及与基础鉴定委托的并存或替代关系。
