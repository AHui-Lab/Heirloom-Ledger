# 第一章《旧账未清》可玩规格

来源：DEC-069、CORE_LOOP、AI_BOUNDARIES、UX_FLOW、EVENT_SYSTEM 与首次试玩反馈。用户授权在 Godot 原型中实现本轮规格；下列数值为可调原型参数，非 locked 规则。

## 玩家体验与故事

返乡接店后，玩家发现爷爷账本中一批没有价格、只写“暂存”的旧物。退休茶庄职工孙玉梅寻回父亲的旧物；旧账保管人周伯安坚持当年的手续；经纪人何景明想将一批器物打包送拍。爷爷并非藏宝谜题的全知安排者，他当年在帮助熟人保管旧物时没有把手续做完，留下真实的人情难题。

章内事实：旧账“周”是保管交接人的签名，不是原藏家；茶庄旧照能证明部分旧物在场，但不能单独证明所有权；一张交接存根明确暂存而非买断；何景明持有的转售清单混入了一件后配物。玩家通过交易、来客回访、查证和外出发现这些事实，最后选择补齐记录归还寄存物、在知情同意后公开出售，或保留未解决事项继续经营。不能仅因资金高或亲近某人就取得所有真相。

物件与人物均为原创内容。现实博物馆资料用于知识背景；不将简化的鉴定线索写成现实鉴定保证。

## 内容清单

- 10个营业日，每日4名常规名额（2买2卖），上午/下午各2名；教学/恢复日可例外，特殊事件明确标记。
- 8名重要NPC：赵庆生、林若岚、孙玉梅、吴致远、周伯安、许闻溪、何景明、陈素琴。
- 至少24件独立器物，各有类别、玩家可见描述、来源层级、估价范围、线索与知识要求、后台属性和流转标识；物品不能重复出售或重复出现。
- 开场、纯经营主题、条件回访、旧账线索、三类章节收束；三种外出地点。

## 规则与操作

经营：观察免费；首次正式鉴定在卖货成交前完成。有效新主题消耗耐心，重复调查额外消耗；普通确认、查看、回答客人的必要问题免费。耐心耗尽转最终报价/选择，仍可成交。道歉仅在受冒犯后一次有效。收购不得超出资金，出售须推荐在库物件；全部资金与物权原子结算。

鉴定：按类别知识与经验解锁线索。没有决定性证据时显示1～99整数概率；发现有资格识别的决定性瑕疵显示“判定为假”。记录保留，成长后主动复核才更新，不重复刷同一记录奖励。类别确定，推测年代与权威年代分开。

辅助：当前物件事实卡显示来源原话、已知线索和历史判断。买家提出的问题由Core选取来源/品相/鉴定依据之一，界面给可编辑回答。确认发送后Core只处理已选语义；修改内容使用自由文本识别并允许澄清。没有资料时提供坦诚未知的回答，不补写传承。

跨日：库存、交易、关系、分类知识、发现事件、角色记忆和剧情旗标跨日保存。每个安全节点可存档；保存不含API Key。重试不重结算，读档不能导致重复支付或重复处罚。

社会后果：分类口碑、全局信誉和NPC关系分别处理。售出问题不立即泄露；预设回访条件满足且发现者能力足够才记录具体发现。传播按关系圈/行业圈/公众圈逐段触发，同问题基础处罚一次，每圈一次主要干预；原交易不自动回滚。发现后给相关知识，不能反复刷奖励。

恢复：资金不足低层级买入且库存为空时，在接下来的安全节点提供一次基础看货委托，完成后取得保底资金；同一天只能触发一次，拒绝不锁死后续恢复。

## 店外玩法

午间或闭店后的明确入口进入古玩街、许闻溪工作室和拍卖预展。店内有未结束交互时只允许查资料，避免丢失客人；外出不消耗实时钟。每个营业日外出内容有一批预编排机会，不刷新刷货。

- 古玩街：先观察与查来源，再决定议价收购或离开，有低价风险和补货作用。
- 专家拜访：选择库存物件，以明确费用换取受专业范围限制的新线索；关系或交接证据满足条件可询问剧情，不自动揭露全物品真相。
- 拍卖：先看预展资料和物件、设置愿意出的价，再竞价/退出。对手预算在Core生成，报价递增，落槌一次结算并明确费用；不要求精确计时。流拍不扣钱，资金不足无法确认。

## UI与表达

主界面为可点击店铺场景、人物立绘/头像、台面物件与交谈区域。货架打开库存，账本打开交易与旧账，笔记打开知识，门口打开外出。入店、选物、成交与阶段过渡有轻量动画与声响；设置可关闭动效与声音。

严格区分NPC、掌柜说话、未出口内心与旁白；客户上下文不包含玩家未说出的判断。场景加载与资料查看免费。正常闭店结算不显示隐藏后台；开发复盘在单独的明确入口。

## 验收证据

本轮实际实现、测试与已知限制见 [[CHAPTER_ONE_ACCEPTANCE]]。本规格仍处于review；下列补充仅为本章可调参数，不提升为locked规则。

- 鉴定后的宽议价区间暂以公开要价的45%～115%作起点，判假后为100～300；不读取权威市场价作为玩家答案。金额不是现实估值或承诺成交价。
- 专家联合知识/经验帮助上限：瓷器75、书画65、文房55、杂项48；每次最多增长6点知识，一天一次，超出范围不收费。
- 一次已被报告的真伪问题产生一次基础影响与学习；传播上限由公开后果中的售价、买家身份决定。已发生影响不因解释被抹去；一圈一次干预。
- 最终授权委托：非自有库存茶器按固定议定价1800成交，1620归原主，180服务费入店账；同时归还原主要求留下的画。不是把寄存物权或全笔货款转给玩家。
- “稍后”类剧情选项延期至次日，不永久消失；拒绝记录或隐瞒条款的选择则可以关闭相关证据路线。

逐项要求：10日完整走通；8名NPC重复出现并有记忆差异；24器物数据与流转；三种外出实际可用；三种收束可由不同状态抵达；资金/库存/事件存读档一致；低资金恢复；两类API协议本地HTTP模拟；空正文/截断/超时/重试不重复交易；建议回答有可查来源；截图验证主场景/物件/外出/结算/配置页且支持较小窗口。

真实模型的风格和稳定性暂不以本地模拟结论代替；用户要求暂不付费联调，此限制明确随验收交付。
