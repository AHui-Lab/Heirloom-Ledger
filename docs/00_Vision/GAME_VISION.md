# Game Vision

## Concept
Heirloom Ledger 是一款发生在虚构的 `X City` 的叙事型古玩店经营游戏。玩家在大城市遭遇裁员后回到故乡，接手已故爷爷留下的古玩店，并通过经营、鉴定、交易、事件和人际关系逐渐理解爷爷的生活并且通过人物故事以及物品线索找到爷爷留下的物品，同时形成自己的收藏与鉴宝人生。

## Player Fantasy
玩家从行业新人开始，学习不同类型和时代器物的知识，承担真假与估值风险，建立信誉和人脉，逐步进入更高层级的交易与收藏圈。

## Long-term Goals
- 延续并经营爷爷留下的店铺。
- 成为真正懂行的古玩从业者，降低但不消除打眼风险。
- 学习知识并积累实际经验。
- 结识业内人物，参与更高层级事件。
- 逐渐了解爷爷过去的人生、找到爷爷留下的宝物，并明白爷爷的良苦用心、人脉及笔记背后的故事。
- 通过自己的经历形成收藏与鉴宝人生。

所有设定均为 Draft；完整主线暂不在此阶段编写。
