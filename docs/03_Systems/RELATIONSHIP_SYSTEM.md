# Relationship System

预约与主动失约不属于 V1 店内章节化营业规则，相关关系后果保留为 Post-V1 候选。
玩家与 NPC 的关系会影响可触发内容。NPC 可以提供知识、货源、信息、事件邀请、工作、帮助请求或人物引荐。

关系至少涉及信任、记忆和社会连接；不同 NPC 擅长领域、阅历、知识和机会类型不同。关系的数值模型、衰减规则和边界尚未确定。

普通公开交易可以逐步累积与器物类别、价格层级或经营表现有关的对外口碑信号，达到门槛后才可能影响后续经营主题。与重要 NPC 的公开成交、相对当前经营层级显著的高价值交易或已经公开传播的重大事件，可以立即成为后续主题来源。单笔普通交易不应立刻建立稳定类别口碑；具体门槛、衰减和重要 NPC 的传播能力尚未确定。

类别口碑按器物类别分别保存精确内部状态，但玩家只看到四档模糊反馈：尚无名气、偶有人提起、逐渐形成口碑、在相关圈子里受到认可。具体内部数值、档位门槛和距离下一档的进度不公开。

类别口碑、全局信誉和 NPC 关系是三个独立但可以受控联动的状态。类别口碑描述玩家在具体器物类别上的经营与专业名声；全局信誉描述店铺整体可靠性和诚信评价；NPC 关系描述某个具体人物对玩家的信任、态度与共同经历。高类别口碑不保证高全局信誉，高全局信誉也不保证某名 NPC 喜欢玩家。

全局信誉按店铺整体保存精确内部状态，玩家只看到四档模糊反馈：声誉受损、尚无定论、口碑稳定、值得信赖。具体数值、档位门槛和距离下一档的进度不公开。全局信誉变化可以通过市场传闻、普通客人的初始态度、营业日开场与结算反馈，但不能把单个 NPC 的私人态度直接当作整个市场的评价。

NPC 关系按具体人物保存精确内部状态，玩家只看到五档统一阶段：防备、生疏、熟悉、信任、深交。内部数值、阶段阈值和距离下一档的进度不公开。阶段的核心含义对所有 NPC 一致，但具体语言、主动程度、信息透露方式和帮助意愿应结合人物性格与身份表现，不能把同一阶段写成完全相同的行为模板。

关系阶段是当前总体态度的摘要，不取代具体记忆、承诺、利益冲突和社会连接。Game Core 需要独立保存足以影响后续交互的重要经历；进入高关系阶段不会删除负面记忆，也不会绕过人物自身立场、能力与利益条件。关系阶段如何与这些记忆共同决定行为尚未细化。

每个事件需要分别指定其影响对象与传播依据。同一事件可以只改变原买家的 NPC 关系，也可以在传播到行业或市场后进一步改变相关类别口碑或全局信誉，但不能自动对三项作相同幅度的处理。具体联动条件和影响幅度尚未确定。

- 系统不在交易当下区分玩家正常误判与故意欺骗。玩家售出的假货，或玩家对年代、来源、真伪等客观属性作出错误陈述的物件，在后续流转或被他人看货时被真实发现后，进入影响判定，但不保证必然损害相关 NPC 的信任、店铺信誉或行业口碑。问题严重程度暂分为轻微、严重、极严重三档；成交价格不影响问题能否被发现，只在真实发现后参与影响判定。同一个问题的基础关系影响只结算一次；后续发现只有在涉及新的关系对象或新的传播圈层时，才可能产生新增关系影响。玩家可以通过解释、请求暂缓转卖、提供补充信息或利用已有关系尝试阻止或延缓传播；每个传播圈层阶段最多进行一次主要干预，具体代价由事件规则决定，V1 不再预设为时间或日程成本。是否成功由 Game Core 根据关系状态、玩家提供的信息和事件条件结算，且不自动撤销交易。传播范围暂分为个人关系圈、行业圈、公众/市场圈，进入更大圈层不是必然结果。是否发酵以及程度由问题严重程度、假货成交价格、买家身份、交易关系和传播范围共同影响。V1 的买家身份暂分为普通买家、懂行买家或行业相关 NPC、有行业影响力的买家，传播与发酵潜力依次提高，但不代表必然损害关系。交易完成时不立即处罚或撤销。

长期关系可以影响 NPC 在交易开始时的初始交谈耐心。单次交谈内不能通过重复寒暄或夸奖持续恢复耐心；玩家冒犯 NPC 后可以尝试一次条件式挽回，是否成功由 Game Core 根据关系、NPC 性格和受冒犯程度决定。具体影响幅度尚未确定。
