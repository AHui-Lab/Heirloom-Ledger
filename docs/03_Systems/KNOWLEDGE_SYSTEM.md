# Knowledge System
Knowledge 不是单一等级，未来可区分器物类别、年代、工艺和鉴定方向。例如玩家可能熟悉某一时期瓷器，却缺乏玉器经验。

知识来源包括爷爷的笔记和 NPC。阅读提供理论知识；接触、鉴定、验证及成功/失败经历，才逐渐形成实际能力。Knowledge 与 Experience 必须保持概念差异。

经验决定玩家能否发现某类器物上的具体瑕疵。玩家缺少相关经验时，即使瑕疵真实存在，也可能无法识别；未能明确判假时，只获得基于当前知识和经验的数值化真品可能性，以及解释当前判断的玩家内心独白。

知识或经验成长不会在后台自动改写库存物件的既有鉴定记录。玩家重新查看、重新鉴定或向买家推荐物件时，才使用当前能力形成新的鉴定结果；旧结果继续保留，以表现玩家判断能力的成长。

V1 不设置独立的正式学习、外出拜访或耗时阅读活动。知识与经验主要通过店内鉴定、交易结果、问题被真实发现、客人交流以及爷爷留下的记录获得。正式学习和活动时间模型保留为 Post-V1 候选。

可中断的个人学习活动在安全节点保存的进度可以跨叙事时段和跨营业日保留。恢复学习时从最近安全节点继续，已投入时间不返还；知识或经验何时实际增加，仍应由该学习活动的结算节点决定，不能仅因保存了部分进度就提前获得完整收益。

玩家曾售出的假货在二次倒卖或被他人看货时被真实发现后，玩家虽然会损失信誉和口碑，但也会通过获知具体瑕疵获得相关知识或经验。学习收益的类别和数量尚未确定。
