# Economy
## Money
资金用于店铺经营、收购藏品、参与拍卖、外出活动和获取更高价值机会。经营收入来自出售藏品、佣金及可能的委托；支出包括经营成本和交易成本。

经济循环应让玩家从较低价值机会逐渐进入更高价值交易，但不以“赚到最多的钱”作为唯一长期目标。价格波动、市场规则、经营成本、资金失败条件和具体数值均为开放设计。

价格表达边界：玩家提出的目标售价、销售价格判断和交易报价属于估值观点或谈判行为，不因为与 Game Core 的当前市场估值不同就自动视为错误或欺骗。Game Core 仍负责保存市场估值、玩家报价、成交价格和资金变化；玩家对年代、来源、真伪等客观属性的明确错误陈述，另由误导或欺诈规则处理。

## V1 经营恢复安全网（暂定）

当玩家资金不足以完成最低层级收购，同时没有可出售库存时，Game Core 应在近期营业安排中保证一次基础鉴定委托。玩家鉴定 NPC 自有物件后获得最低服务费，无需投入本金；错误判断不会取消最低服务费，鉴定质量可以影响额外报酬、学习或口碑。

该收入只应帮助玩家重新进入最低层级交易，并占用营业时间或客户名额，避免主动破产成为高效获利策略。触发阈值、保证出现的时间范围、最低服务费与额外报酬公式均未确定。未来可结合更现实的寄售、代卖、赊账、熟人援助或其他古玩行业经营方式进行修改或扩展。
