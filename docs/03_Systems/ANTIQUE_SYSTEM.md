# Antique System
玩家获取、持有、鉴定、议价和出售古玩。每件古玩未来至少可能包含：类型、年代、真伪、品相、来源、市场价值、收购价、目标售价、相关故事和鉴定难度。

Game Core 秘密保存真实状态；玩家通过观察、交流、知识、经验和验证形成判断。LLM 可表现卖家说法、器物描述、报价、谈判和鉴定反馈，但不能决定真实真伪、年代或价值。

买货客人公开类别、约略价格和年代后，系统可以使用古玩自身的类别、年代和当前市场估值字段对库存进行匹配高亮或优先排序。初次匹配不使用玩家收购价或尚未提出的最终报价；玩家主动提出报价后，系统可以再反馈该报价与买家预算的模糊匹配。该匹配只整理公开条件，不等于真伪判断、利润判断或自动推荐；最终推荐仍由玩家决定，买家是否感兴趣仍由 Game Core 结算。

如果库存中没有完全匹配，系统应保留符合部分公开条件的弱匹配物件，并提示玩家当前没有完全匹配。玩家可以自行选择弱匹配进行推荐和推销，但必须准确说明物件的具体类别；年代或价格偏差不要求玩家主动披露，玩家可以自行组织销售表达。买家是否接受由 Game Core 根据其隐藏需求、预算和反应结算。完全不同大类或明显偏离需求的物件不属于第一版常规推荐范围。

年代匹配应使用买家年代范围与物件当前可用年代信息进行模糊接近度判断：完全落在范围内为高匹配，部分接近或相邻为弱匹配，明显超出为低匹配。该结果不替代玩家对年代的鉴定。

类别是物件的确定基础属性，不采用“疑似瓷器”一类的概率结果。类别匹配应使用层级关系：买家提出父类时，子类物件可以匹配；买家提出具体子类时，精确子类优先，同一父类下的其他子类可以作为较弱匹配；完全不同的大类不匹配。玩家推销弱匹配物件时仍必须使用物件的真实具体类别，不能用推销话术改变类别字段或把弱匹配伪装成精确匹配。该关系用于物件分类整理和库存匹配，不替代玩家对真伪、年代或价值的判断。

玩家选择推荐物件后，系统自动展示并带出其确定具体类别，作为物件介绍和后续对话的固定事实。玩家可以在此基础上自由推销，但不能通过自由文本省略或改写类别。

玩家对市场价格、预期售价或报价的表达属于估值观点、销售表达或谈判行为，价格与 Game Core 市场估值不一致本身不等于说谎。年代、来源、真伪等客观属性的明确错误陈述，才进入后续误导或欺诈规则的判断范围。

## Identification Result

每件假货可以具有一个或多个可识别瑕疵。Game Core 保存瑕疵事实，以及识别这些瑕疵所需的相关经验或能力。

- 如果玩家当前经验足以发现具有决定性的明显瑕疵，玩家可以获得明确的“判定为假”结论。
- 如果玩家没有发现足以判假的瑕疵，Game Core 根据玩家知识、经验、已获得线索和器物难度生成真品概率，并以 `1%–99%` 的整数向玩家显示。概率模式不出现 `0%` 或 `100%`。
- 没有发现假货证据不等于证明为真；真实状态始终由 Game Core 隐藏保存。

鉴定反馈由两部分共同构成：

1. Game Core 生成、以 `1%–99%` 整数显示且不含小数的真品概率。
2. LLM 根据 Game Core 授权的已发现线索、概率与不确定性生成的玩家内心独白。

内心独白用于解释玩家为何形成当前判断，使鉴定反馈更自然，但不得新增玩家尚未发现的瑕疵、改变数值概率或泄露物件真实状态。

## Identification Updates

- 主动鉴定过程中，每获得一条有意义的新线索，Game Core 重新计算真品概率，LLM 根据更新后的授权信息重新生成内心独白。
- 库存物件不会因玩家知识或经验成长而在后台自动刷新。
- 玩家重新查看、重新鉴定或向买家推荐库存物件时，Game Core 根据当前能力和已有线索重新计算。
- 购入时及之后各次鉴定的概率、已发现线索和能力状态都应保留，供玩家比较判断变化。

没有当前客人时，对库存物件进行独立鉴定属于可中断的耗时店内活动。新客人到访时，Game Core 在该鉴定活动的安全节点暂停并保存有效进度；已消耗时间不返还，客人交易结束后可以继续。当前客人在场时，只有本次交易涉及的物件鉴定属于必要交易流程，无关库存物件的独立鉴定不能开始。

独立鉴定在安全节点保存的活动进度可以跨叙事时段和跨营业日保留。玩家之后继续时不需要从头开始，但已经用于该鉴定的时间不会返还。鉴定活动进度与已经形成的正式鉴定记录需要区分：只有达到规则规定的输出节点后，才新增或更新一次可供玩家查看的鉴定结果。

## Post-sale Discovery

普通交易完成后钱货两清，不因后来发现假货而自动退款或撤销。Game Core 保存已售物件的交易与流转状态。

真实为假的物件，或玩家曾对年代、来源、真伪等客观属性作出错误陈述的物件，可能在二次倒卖、被其他 NPC 看货或类似后续场景中，被具备相关经验的人识别出问题。交易完成时不立即揭示或处罚；相关客观错误被真实发现后，只进入后续影响判定，不保证必然产生信誉、口碑、关系或事件后果。问题严重程度只描述问题本身对物件真实价值与行业判断的影响，分为三档：轻微问题是局部瑕疵或有限价值偏差；严重问题是真伪、年代、来源等重大错误，明显改变价值判断；极严重问题是关键属性完全虚构，或物件本质与玩家陈述严重不符。同一物件的多个问题分别记录，并由 Game Core 独立判定是否被当前发现者识别；一次事件只反馈被识别的问题，未被识别的问题继续作为隐藏风险保留。本次影响判定只使用本次实际被识别的问题，不提前按隐藏问题的真实严重程度产生后果。物件整体主问题等级仍取真实存在的问题中的最高等级。同一个问题的基础后果只结算一次；后续发现只有在进入新的传播圈层、涉及新的关系对象或满足新的事件条件时，才可能产生新增影响。传播范围暂分为个人关系圈、行业圈、公众/市场圈。个人关系圈进入行业圈需要买家向同行咨询、再次转卖时请懂行者看货或进入正式鉴定；行业圈进入公众/市场圈需要形成公开争议、重要人物介入或事件被公开传播。没有满足明确触发条件时，问题停留在当前圈层。成交价格不影响问题能否被发现，也不决定问题严重程度，只在真实发现后参与影响判定。是否发酵以及发酵程度由 Game Core 根据问题严重程度、假货成交价格、买家身份、交易关系和传播范围决定。V1 的买家身份暂分为普通买家、懂行买家或行业相关 NPC、有行业影响力的买家，传播与发酵潜力依次提高，但不代表必然产生后果。第一版不在交易当下强行区分玩家是正常误判还是故意欺骗。

发现者暂分为三个能力层级：普通客人只能发现非常明显的问题；懂行买家或相关 NPC 能发现较隐蔽的问题；专业鉴定人拥有最高的相关发现能力。层级只影响此次检查能否识别问题，不直接决定后果轻重。实际发现结果由 Game Core 结合物件问题、可观察线索和发现情境结算，不保证高能力发现者每次都能识别；后果强度主要由问题严重程度、假货成交价格、买家身份、交易关系和传播范围决定。买家身份层级影响传播与发酵潜力，发现者能力层级只影响能否识别问题。

标准范例见 [[CORE_LOOP#Scenario D：已售假货在二次转卖时被懂行买家发现]]。该范例用于验证后续发现和长期后果，不代表每件假货都会按同一事件顺序暴露。

具体数据结构、瑕疵识别条件、真品概率公式和发现事件规则尚未确定。
