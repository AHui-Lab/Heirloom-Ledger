# Characters

V1 的重要 NPC 使用统一的五档关系阶段：防备、生疏、熟悉、信任、深交。Game Core 保存精确内部状态，玩家只看到阶段与人物行为反馈。阶段的机械含义统一，但每名 NPC 应根据性格、身份和表达习惯以不同方式表现同一阶段，不能使用完全相同的关系台词模板。

关系阶段不等于人物的完整记忆。角色还需要保留与玩家有关的重要事件、承诺、冲突、帮助、交易与社会连接；高关系阶段不会自动覆盖这些具体事实，也不保证人物在违背自身利益或立场时帮助玩家。
## Player
玩家是长期在大城市工作的年轻人，早年离开故乡，与在 X City 经营文玩店的爷爷接触不多。爷爷去世后，玩家在大城市遭遇裁员，经历长期高压生活后回到 X City，暂时接手店铺，逐渐发现古玩行业可能是自己真正想走的道路。

## Grandfather
已故爷爷曾经营古玩店，留下记录鉴宝经验、人脉和经历的笔记。他的人生、关系网络及店铺背后的故事将逐步揭示，但当前不编写完整传记或主线。

## NPC Framework
重要 NPC 未来至少可能包含：Identity、Background、Personality、Expertise、Goals、Relationship、Trust、Memory、Social Connections、Current Situation。具体 NPC Agent 架构尚未确定。

日常卖货客人不使用固定、互斥的“卖家类型”。其交易状态由 Game Core 保存的认知状态、表达诚实度、出售动机和谈判策略组合形成。同一个客人可以同时具备多个状态，例如了解物件价值、急需资金并试探玩家是否懂行。NPC 提供错误信息不必然代表故意欺骗，也可能来自自身认知错误。

日常买货客人同样不使用固定、互斥的“买家类型”。其交易状态由购买目的、专业程度、预算弹性、购买急迫度和谈判策略等可组合维度形成。玩家需要通过交谈和买家对物件、报价的反应进行判断，而不是直接读取完整状态。

买家初次只表达宽泛的购买方向，不直接公开完整用途、品质要求、真实预算、预算弹性和急迫度。表达不完整可能来自无知、谨慎、试探或不愿暴露预算，不必然代表故意欺骗。

买卖双方各维度的具体枚举、组合限制、持续时间，以及日常客人与重要 NPC 是否共用同一套状态模型，仍待后续 NPC 系统设计。

卖货客人在单次交互中还拥有有限的交谈耐心或等价阈值，防止玩家通过无限追问穷举隐藏信息。耐心由 Game Core 结算，LLM 只负责表现客人态度的变化。后台精确值不直接向玩家显示，玩家只能看到 NPC 态度与模糊阶段提示。具体阶段和行为消耗尚未确定。

普通情况下，耐心耗尽不会立即取消交易，而是让 NPC 停止回答新问题并要求玩家进入最终报价。玩家继续拖延、施压或指控时，NPC 才可能离店；急躁或已受冒犯的 NPC 可以更早离店，但需要提前表现态度变化。

寒暄或夸奖不能反复恢复耐心。玩家冒犯 NPC 后可以尝试一次道歉、解释或主动退让；是否被接受取决于 NPC 性格、关系和受冒犯程度，成功也只能恢复少量耐心且不超过初始上限。长期关系主要影响交易开始时的初始耐心。
