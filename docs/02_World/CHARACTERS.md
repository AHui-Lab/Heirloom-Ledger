# Characters
## Player
玩家是长期在大城市工作的年轻人，早年离开故乡，与在 X City 经营文玩店的爷爷接触不多。爷爷去世后，玩家在大城市遭遇裁员，经历长期高压生活后回到 X City，暂时接手店铺，逐渐发现古玩行业可能是自己真正想走的道路。

## Grandfather
已故爷爷曾经营古玩店，留下记录鉴宝经验、人脉和经历的笔记。他的人生、关系网络及店铺背后的故事将逐步揭示，但当前不编写完整传记或主线。

## NPC Framework
重要 NPC 未来至少可能包含：Identity、Background、Personality、Expertise、Goals、Relationship、Trust、Memory、Social Connections、Current Situation。具体 NPC Agent 架构尚未确定。
