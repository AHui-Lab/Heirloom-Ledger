# LLM Design
核心原则：**Game Core decides reality. LLM interprets and expresses reality.**

LLM 可负责 NPC 对话与反应、动态事件表现、随机事件候选、行为意图、客人语言、古玩背景描述、报价与谈判语言、故事文本、记忆摘要，以及依据当前 World State 生成合理表达。

LLM 不拥有资金、库存、真实真伪、内部年代、核心市场价值、最终随机结果、胜负、任务条件或物品拥有权的最终决定权。所有权威事实由 Game Core 提供并校验。
