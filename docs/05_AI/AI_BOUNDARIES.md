# AI Boundaries
## Authority
Game Core 是现实、规则、随机数和条件判断的唯一权威。LLM 只能读取经过授权的状态上下文，输出必须经过解析、校验和 Game Core 执行。

## Allowed
对话、语气、叙事表现、候选行为、候选事件、描述、谈判措辞和记忆摘要。

## Forbidden as Final Authority
不得直接修改资金、库存、物品真实属性、核心价格、随机结果、胜负、任务完成条件或世界核心事实。

NPC 是否采用独立 Agent、调用方式、云 API 或 BYOK 尚未确定，记录于 [[OPEN_QUESTIONS]]。
