# AI Boundaries
## Authority
Game Core 是现实、规则、随机数和条件判断的唯一权威。LLM 只能读取经过授权的状态上下文，输出必须经过解析、校验和 Game Core 执行。

## Allowed
对话、语气、叙事表现、候选行为、候选事件、描述、谈判措辞、记忆摘要，以及依据 Game Core 授权的鉴定概率、已发现线索和不确定性生成玩家内心独白。

LLM 可以依据 Game Core 已确定的卖家认知状态、表达诚实度、出售动机和谈判策略，生成一致的说法、隐瞒、试探与谈判反应，但不能自行改变这些隐藏状态或物件真相。

LLM 可以依据 Game Core 已确定的买家购买目的、专业程度、预算弹性、购买急迫度和谈判策略，生成询问重点、对推荐物件的反应、预算表达与谈判措辞，但不能自行改变买家真实需求、预算能力或购买决定。

LLM 只能表达 Game Core 当前授权的买家宽泛需求或已暴露的具体信息，不得擅自补全买家未公开的用途、预算、品质要求或急迫度，也不得把表达不完整直接解释为故意欺骗。

等待队列中的客人身份、买货或卖货来意、需求和到访顺序由 Game Core 保存。LLM 在客人正式进入交互前只能表达“仍有客人在等待”这一授权状态，不得提前生成或泄露具体人数、身份、来意和需求。

LLM 不得重排买家与卖家的全日顺序，也不得自行创建“连续 3 名同类客人”的剧情或主题例外。普通最多连续 2 名的校验和任何受控例外都必须在营业日生成时由 Game Core 完成。

LLM 不得自行把客人指定为判断挑战，也不得创造挑战来源、决定正确答案、补写未授权的器物矛盾或将普通表达曲解为欺骗。Game Core 必须预先提供可表达的线索、授权条件和不确定性；LLM 只能自然表现这些信息。判断挑战标签本身不向玩家披露。

普通标准营业日 1～2 名、教学或恢复日允许 0 名、重要剧情日最多 3 名的判断挑战数量及例外，均由 Game Core 在生成队列时确定和校验。LLM 不得为了增强戏剧性把普通客人升级为挑战，也不得追加超过上限的挑战。

LLM 不得决定当天是否“需要一段剧情”。剧情客人、消息、回访和爷爷线索必须由 Game Core 根据预先编排节点或事件条件触发；LLM 只能表达已授权的剧情内容。剧情可以隔数日出现，也可以连续出现，但这种节奏不由 LLM 临时补足。

LLM 可以依据 Game Core 已选择的经营主题生成开场氛围、市场传闻和客人对相关话题的自然表达，但不能自行选择或更换主题、扩大主题影响、修改生成权重或事后改变来客与器物状态。LLM 不得把趋势表达成保证获利、保证捡漏或系统推荐的正确策略。

当主题包含玩家驱动来源时，LLM 只能引用 Game Core 标记为已经公开、被 NPC 知道或已经传播的信息。LLM 不得根据隐藏库存、尚未发现的真假问题或未传播的交易事实编造“外界已经听说”的说法，也不得把玩家形成的类别口碑只表现为有利结果。

LLM 不得根据单笔普通成交自行宣布玩家已经形成某类口碑，也不能自行判断某笔交易是否足够重要或高价值。普通信号是否达到门槛、重要事件是否立即取得主题资格以及最早影响哪个营业日，均由 Game Core 决定；LLM 只能表现已经授权的传播与反馈。

LLM 只能获得并表达 Game Core 授权的类别口碑模糊阶段及变化原因，不得输出内部精确值、进度百分比、档位门槛或“还差几次交易升级”等推断。V1 可见阶段为尚无名气、偶有人提起、逐渐形成口碑、在相关圈子里受到认可。

LLM 不得把类别口碑、全局信誉和 NPC 关系混写为同一个声望结果，也不得因为其中一项变化就自行生成另外两项变化。只有 Game Core 明确提供各自的结算结果、影响对象和可公开原因后，LLM 才能分别表现专业名声、店铺诚信评价或具体人物态度。

LLM 只能使用 Game Core 授权的全局信誉阶段“声誉受损、尚无定论、口碑稳定、值得信赖”及可公开变化原因，不得输出或推算内部数值、阶段阈值、百分比进度和还需多少行为才能升级。个别 NPC 的态度不能被 LLM 擅自扩展为市场整体评价。

LLM 只能使用 Game Core 授权的 NPC 关系阶段“防备、生疏、熟悉、信任、深交”、相关人物性格和可调用记忆生成表现。LLM 不得泄露精确关系值或门槛，不得仅因阶段较高就删除负面记忆、创造未发生的共同经历，或让 NPC 无条件违背自身立场和利益。

玩家暂时切出当前客人界面时，LLM 不得自行继续对话、生成新的 NPC 行为、消耗耐心、推进交易阶段或判定客人离店。玩家返回后，LLM 只能依据 Game Core 保存的同一交互状态继续表达。等待队列中的其他客人仍受信息隐藏规则约束。

LLM 不得把界面切换解释为玩家已经开始学习、外出或其他 V1 范围外活动。LLM 输出速度、玩家阅读时长、界面停留时长和现实等待时间都不得推动上午、午间、下午或晚上阶段，也不得触发新客人或消耗 NPC 耐心。营业阶段只能由 Game Core 在当前阶段的安排完成后推进。

库存匹配高亮或排序必须依据 Game Core 提供的公开类别、约略价格和年代要求、物件属性及当前市场估值生成；初次匹配不得使用玩家收购价或尚未提出的最终报价。报价后的预算匹配反馈也必须由 Game Core 生成。LLM 不得自行改变匹配结果，也不得把高亮物件表达为“系统认定最值得出售”或“保证适合买家”。

当 Game Core 标记不存在完全匹配但保留了弱匹配候选时，LLM 可以表现买家对玩家主动推荐弱匹配的兴趣、疑虑或拒绝，但不能自行增加候选物件、把完全不同大类物件加入常规推荐，或替 Game Core 决定买家接受推荐。完全偏离公开需求的主动推销属于尚未进入第一版核心规则的后续玩法。

玩家推荐或推销物件时，类别事实展示由 Game Core/UI 自动提供，不由 LLM 决定是否出现。LLM 可以依据 Game Core 提供的确定类别和匹配结果，帮助表达“这件物品实际属于什么类别”以及玩家为何认为它值得考虑。玩家不必使用固定话术主动披露年代或价格偏差，但 LLM 不得改写物件的具体类别或把弱匹配表达成完全匹配。若玩家明确选择隐瞒或误导性的销售行为，LLM 可以表现该已选择的行为，但必须作为候选表达交由 Parser 和 Game Core 校验，不能自行判定其成功、改变物件事实或决定后果。买家是否相信、感兴趣或接受推荐仍由 Game Core 结算。

玩家的价格判断、目标售价和报价属于销售或谈判表达，不因与市场估值不同就自动构成错误事实。LLM 可以表现玩家选择的价格立场，但不能修改 Game Core 的市场估值、成交价格或资金结果；对年代、来源、真伪等客观属性的错误陈述及其后果必须交由 Game Core 识别和结算。

 客观属性的错误陈述在交易完成时不应由 LLM 立即揭示、处罚或判定玩家动机。只有当 Game Core 在后续场景中判定该错误被真实发现时，LLM 才可以表现 NPC 反馈、信誉影响或学习反馈；第一版不要求 LLM 在交易当下区分正常误判与故意欺骗。玩家尝试解释、请求暂缓转卖或提供补充信息时，LLM 负责表现对话，Game Core 负责决定当前传播阶段是否仍有主要干预机会、干预是否成功、是否延缓传播以及是否产生新增影响。每个传播阶段的主要干预最多一次，具体代价由事件规则决定，V1 不再预设为时间或日程成本。

后续发现事件中，发现者能力层级由 Game Core 提供，暂分为普通客人、懂行买家或相关 NPC、专业鉴定人。问题严重程度由 Game Core 提供，V1 暂分为轻微、严重、极严重三档；同一物件的多个问题分别判定，LLM 只能表现本次已经被 Game Core 识别的问题，不能因一个问题被发现就自行揭示其他隐藏问题。对于同一个问题，LLM 只能表现 Game Core 已结算的基础后果或新增影响，不能重复生成同一基础惩罚。传播范围暂分为个人关系圈、行业圈、公众/市场圈，LLM 不能自行表现问题已经进入更大圈层。LLM 可以依据已结算的发现结果表现检查、疑问、识别和反馈，但不能自行决定发现者是否成功识别客观错误，也不能仅根据发现者层级决定是否处罚或后果强度。成交价格不参与发现判定，只在 Game Core 判定问题已被真实发现后参与影响结算。原买家身份由 Game Core 提供，V1 暂分为普通买家、懂行买家或行业相关 NPC、有行业影响力的买家；发现后是否发酵及其程度由 Game Core 根据问题严重程度、假货成交价格、买家身份、交易关系和传播范围结算。

年代的高匹配、弱匹配或低匹配只能作为公开条件的模糊筛选结果。LLM 不得把匹配等级表达为对物件绝对年代的确认。

类别的精确匹配、同父类弱匹配或不匹配由 Game Core 根据物件确定类别字段生成。LLM 可以表达该确定类别，但不得借此替玩家确认真伪、年代、品相或价值。

LLM 可以依据 Game Core 提供的交谈耐心阶段表现耐烦、警惕、不满、拒答或催促，但提问是否有效、耐心如何变化、是否耗尽以及交易是否因此结束，必须由 Game Core 决定。

对于玩家自由文本，LLM 或解析层可以提出“普通回应、澄清、新主题追问、重复追问、施压、质疑、指控、基于线索追问”等候选对话行为，但候选结果必须经过校验后才能由 Game Core 结算耐心。原始消息数量本身不直接等于耐心消耗。

当 Game Core 标记交互进入最终报价阶段时，LLM 应表现 NPC 拒绝新问题并催促报价，但不能自行开放新的调查线索、强制成交或决定 NPC 离店。

当 Game Core 标记买货交互进入最终选择阶段时，LLM 应表现买家不再接受新的调查问题或库存推荐，但不能自行增加可选物件、强制购买或决定买家离店。

LLM 可以把玩家的道歉、解释或主动退让识别为一次候选挽回行为，并表现 NPC 接受或拒绝后的反应；是否允许尝试、是否成功以及恢复多少耐心仍必须由 Game Core 决定。LLM 不得通过生成寒暄或友好措辞自行恢复耐心。

## Forbidden as Final Authority
不得直接修改资金、库存、物品真实属性、核心价格、鉴定概率、玩家已发现线索、随机结果、胜负、任务完成条件或世界核心事实。鉴定内心独白不得新增未授权瑕疵、改变概率或泄露真实真伪。

NPC 是否采用独立 Agent、调用方式、云 API 或 BYOK 尚未确定，记录于 [[OPEN_QUESTIONS]]。
