# Design Pillars

1. **判断而非自动正确**：鉴定包含信息不完整、概率和风险；成长降低错误概率，但不保证绝对正确。
2. **经营与故事互相推动**：资金、藏品和信誉影响可见事件；事件、知识和人脉反过来影响经营机会。
3. **人物驱动世界**：NPC既是故事角色，也是知识、货源、信息和机会的入口。
4. **事实与表达分离**：Game Core 决定现实，LLM 解释并表达现实。
5. **文档先于实现**：设计文档是主要事实来源，不明确的内容保持开放。
