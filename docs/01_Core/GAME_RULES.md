# Game Rules
- 核心现实由 Game Core 决定，LLM 不得成为唯一状态管理者。
- 资金余额、库存、古玩真伪、真实年代、核心价值、随机结果、胜负和条件检查必须由 Game Core 决定。
- 鉴定不是“学会技能后永远正确”；知识与经验越高，错误概率越低，高难度器物仍可能误判。
- 器物的基础类别是物件的确定属性，不采用“疑似瓷器”一类的概率结果；真伪、年代、品相和市场价值则可以存在鉴定不确定性。
- 玩家选择推荐库存物件后，系统必须自动展示并带出该物件的确定具体类别；玩家可以继续自由推销，但不能通过对话省略或改写这一类别事实。
- 玩家对物件价格的表达属于估值观点、销售表达或谈判报价，价格高低本身不直接构成说谎；年代、来源、真伪等客观属性的明确错误陈述，才可能进入误导或欺诈判定。
- “读过爷爷笔记”不等于掌握；掌握需要接触、鉴定、验证以及成功或失败经历。
- 重大故事阶段由 NPC 事件、能力、资金、人脉、经历和成就共同推进。
- 鉴定结果分为两层：玩家经验足以识别决定性瑕疵时可以明确判假；没有发现足以判假的瑕疵时，只能获得基于当前知识和经验、以 `1%–99%` 整数显示且不含小数的真品概率，不能因此确认物件为真。概率模式不出现 `0%` 或 `100%`；明确判假是独立结果。玩家同时获得由 LLM 根据 Game Core 授权线索生成的内心独白。
- 主动鉴定时，获得有意义的新线索会更新概率与内心独白；库存物件不在后台自动更新，只有重新查看、重新鉴定或向买家推荐时才按当前能力重新计算。历史鉴定记录必须保留。
- 第一版普通古玩买卖遵循“买定离手、钱货两清”：交易完成后不自动退款或撤销。对于已售假货或玩家对年代、来源、真伪等客观属性作出的错误陈述，交易完成时不立即揭示或处罚；只有在后续流转、看货或类似场景中被真实发现时，才进入信誉、口碑、关系或事件影响判定，但不保证必然产生影响。成交价格不影响问题能否被发现，只在问题已经被真实发现后参与发酵程度结算。问题严重程度暂分为轻微、严重、极严重三档；同一物件存在多个问题时，最高严重程度为主问题等级，其余问题作为附加影响因素保留。玩家可以在问题发现后尝试联系买家解释、请求暂缓转卖、提供补充信息或利用已有关系进行有限干预；每个传播圈层阶段最多进行一次主要干预，其明确代价由事件规则决定，V1 不再预设为时间或日程成本。干预不自动撤销交易且不保证成功。是否发酵以及发酵程度由 Game Core 根据问题严重程度、假货成交价格、买家身份、交易关系和传播范围决定。V1 的买家身份暂分为普通买家、懂行买家或行业相关 NPC、有行业影响力的买家；三者依次具有较小、中等和较大的传播与发酵潜力，但都不代表必然产生后果。第一版不在交易当下强行区分玩家是正常误判还是故意欺骗。
- V1 使用上午营业、午间过场、下午营业、晚上闭店结算的章节化流程，不模拟连续时间、不显示精确时钟，也不设置行动点。
- 标准营业日每天约 4～6 名客人，包括 2～3 名卖货客人和 2～3 名买货客人；上午与下午各安排 2～3 名。4 名时按 2/2 分布，5 名时按 2/3 或 3/2 分布，6 名时按 3/3 分布。5 名时哪一段安排 3 名由 Game Core 根据买卖组合、剧情、经营主题和节奏决定。
- 买货与卖货身份不设置每个阶段的固定配额。剧情客人和特殊客人默认占用标准名额；只有 Game Core 明确标记的重要剧情例外可以突破单阶段与全日人数范围，LLM 不得自行增加来客。
- 普通情况下，全日来客序列最多连续出现 2 名同类客人，不得连续安排 3 名买家或 3 名卖家；上午与下午的切换不重置连续计数。剧情或经营主题需要时可以由 Game Core 显式标记例外，LLM 不得自行调整顺序。
- 除教学日或 Game Core 明确标记的经营恢复日外，每个标准营业日至少安排 1 名隐藏的判断挑战客人。判断挑战可以与买货、卖货、剧情锚点或后果回访等其他职责重叠，不等同于骗子、高价值器物或必然获利机会。
- 普通标准营业日安排 1～2 名判断挑战客人，不得让全部来客都成为判断挑战；教学日和明确的经营恢复日允许为 0 名。重要剧情日最多可以安排 3 名，但必须由剧情数据显式声明例外并由 Game Core 验证。
- 每项判断挑战必须由 Game Core 预先定义挑战来源、至少一项玩家有机会发现的有效线索、可利用线索的相关行为及具有差异的可能结果。线索不保证完全确定或必然被发现，但不得采用没有可用依据的随机猜测、系统强制失败或 LLM 临时创造矛盾。
- 卖货分支中的观察、询问和收购前鉴定，以及买货分支中的查看、重新评估、推荐、议价和出售，均属于必要交易流程，不受到时间资源限制。
- 午间过场及当前客人交互期间允许玩家查看库存、账本、历史交易、人物已公开资料和鉴定记录；查阅与界面切换不消耗 NPC 耐心，也不改变营业阶段。
- 外出、拍卖、正式学习、预约冲突、耗时店内活动、中断恢复和连续时间成本不属于 V1 玩法，保留为 Post-V1 候选。
- 重要剧情节点由设计者编排，常规经营案件由 Game Core 生成或选取，LLM 负责表达。剧情不要求每天发生，可以隔数日出现，也可以在关键阶段连续发生。
- 没有重要剧情推进的纯经营日必须具有一个由 Game Core 选择的经营主题；剧情日可以按内容需要附带兼容主题。主题只调整来客、器物、动机、话题或市场氛围等候选内容的生成权重，不保证利润、捡漏或特定结果，也不改变已经生成的器物真相和 NPC 隐藏状态。
- 经营主题可以由世界趋势与玩家已对外形成的状态共同驱动。玩家驱动来源只包括公开陈列、历史成交、已形成的类别口碑、NPC 关系和已经传播的事件结果；隐藏库存、未被发现的真假问题和未传播事实不能影响外界本不可能知道的来客趋势。
- 玩家形成某类经营口碑后，相关主题可以同时增加合适买家、普通卖家、高价试探者或带有风险的交易机会，不能把玩家驱动主题实现为单向正反馈奖励。
- 单笔普通公开交易只累积对外经营信号，达到门槛后才可以形成后续经营主题。重要 NPC 的公开成交、相对当前经营层级显著的高价值交易或已经公开传播的重大事件，可以直接获得主题候选资格，但最早只能影响下一个尚未生成的营业日。
- Game Core 按器物类别保存精确的类别口碑状态，玩家只看到“尚无名气、偶有人提起、逐渐形成口碑、在相关圈子里受到认可”四个模糊阶段，不显示精确值、进度条或阶段门槛。
- 类别口碑、全局信誉和 NPC 关系是三个独立的权威状态：类别口碑表示玩家在具体器物类别上的经营与专业名声，全局信誉表示店铺整体可靠性与诚信评价，NPC 关系表示具体人物对玩家的信任和态度。
- 全局信誉由 Game Core 保存精确内部值，玩家只看到“声誉受损、尚无定论、口碑稳定、值得信赖”四个模糊阶段，不显示精确值、进度条或阶段门槛。
- NPC 关系由 Game Core 按人物保存精确内部值，玩家只看到“防备、生疏、熟悉、信任、深交”五个统一阶段，不显示精确值、进度条或阶段门槛；不同人物依据性格采用不同表达。
- NPC 关系阶段只是当前态度的概括，具体记忆、承诺、利益冲突和社会连接必须另行保存；高关系阶段不自动清除负面记忆，也不保证无条件帮助。
- 一次事件可以依据明确原因分别影响一项、两项或三项，但不得使用统一声望值无差别加减，也不得从其中一项自动推导其他状态。假货被发现后的影响范围必须结合涉及类别、买家身份、关系对象和传播圈层由 Game Core 分别结算。
- 经营主题以开场信息、传闻、客人交谈和来客构成等模糊信号呈现，不向玩家显示后台倍率或最优策略。LLM 只能表达 Game Core 已选择并授权的主题及影响。
- 当前交互期间，玩家只知道是否还有客人在等待，不显示等待客人的具体人数、身份、买货或卖货来意、需求和到访顺序；这些权威状态由 Game Core 保存，并在客人正式进入交互后通过对话逐步表现。
- 当前客人交互可以暂时切出并通过可识别的头像、柜台卡片或等价入口返回。Game Core 必须保留对话、已公开信息、耐心与交易阶段；LLM 不得在后台自行推进交互。
- V1 暂定提供经营软失败安全网：当玩家资金不足以完成最低层级收购且没有可出售库存时，Game Core 在近期营业中保证一次基础鉴定委托。完成委托获得不因判断错误而取消的最低服务费，使玩家能够重新进入最低层级交易；鉴定质量只影响额外收益。具体阈值、时机和数值尚未锁定。
- 未确定的时间、失败、结局和公式不得被实现为永久规则。
