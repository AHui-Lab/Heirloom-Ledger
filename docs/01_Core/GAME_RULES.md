# Game Rules
- 核心现实由 Game Core 决定，LLM 不得成为唯一状态管理者。
- 资金余额、库存、古玩真伪、真实年代、核心价值、随机结果、胜负和条件检查必须由 Game Core 决定。
- 鉴定不是“学会技能后永远正确”；知识与经验越高，错误概率越低，高难度器物仍可能误判。
- “读过爷爷笔记”不等于掌握；掌握需要接触、鉴定、验证以及成功或失败经历。
- 重大故事阶段由 NPC 事件、能力、资金、人脉、经历和成就共同推进。
- 未确定的时间、失败、结局和公式不得被实现为永久规则。
