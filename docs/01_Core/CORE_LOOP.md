# Core Loop

## 经营循环
获取或收购古玩 → 鉴定与判断 → 承担真假和估值风险 → 来客→ 挑选商品→ 出售 → 随机触发二次鉴定→ 获得利润 → 支付经营成本 → 获得进入更高价值交易的资金 → 接触更好的藏品。

- 获取或收购古玩：原始爷爷的库存、找到爷爷藏起来的宝藏、顾客带来货物出售、通过玩家进行拍卖获得。
鉴定与判断：玩家通过目前学识进行鉴定，给出该货物的真假可能性以及估值。
承担真假与估值风险：货物可能有真有假，根据估值以及卖家的出价，估计出出手后可以获得的利润，来判断是否收购下承担风险。
来客：根据自己的店的声望和物品的质量来获取不同质量的客人，会对客人鉴定的水平，以及其出价和选择商品造成影响。
挑选商品：客人挑选商品并且出价，玩家会看到该商品购入时的鉴定程度以及描述，并且会触发玩家自动二次判断，结合玩家当前的学识水平，更新对该物件的判断，新老判断都会展现。
出售：买家选择商品进行出价，玩家可以看到购入时和当前对该商品的判断，来对买家进行介绍商品。玩家结合对古玩的估价和买家的状态和出价判断中间的利润和风险，风险主要是并结合人物与玩家的对话玩家可以判断该次买卖是否有可能会出现二次鉴定的情况。最终综合的进行考量。决定当时选择出售/加价/不想出售。
随机触发二次鉴定：二次触发鉴定，当玩家对物件的判断不够准确，而买家似乎对该物件有所考究时，就有几率触发二次鉴定，并且玩家越不熟悉，买家越熟悉就越容易触发。二次触发是由专业鉴定机构出鉴定报告，若为假，则触发惩罚机制，为真则奖励提高声望和学识。
获得利润：出售商品若不触发二次鉴定则直接收取利润，若触发二次鉴定，则根据鉴定结果确定。
支付经营成本：根据经营时间流动自动扣除，类似于现实中的水电费。
获得更高价值交易的资金：买卖古玩为获取资金的主要途径，资金水平越高越能收到更高价值的物件，但是打眼付出的成本也就更大。资金的水平会决定自己能进入的拍卖会水准，并且能触发NPC的事件：隐藏拍卖会等等。
接触更好的藏品：当资金量充足，店铺信任度高，来卖货的顾客带来的藏品也就越好。资金充足接触的拍卖会也就更好。
## 成长与故事循环
经营店铺 → 接触 NPC → 触发事件 → 参与鉴宝、收货、拍卖或交流 → 获得知识、经历、人脉或报酬 → 提升鉴定能力 → 解锁更高层级人物和事件 → 了解爷爷的故事。

经营店铺与NPC：特殊客人作为NPC出现、爷爷的笔记中提到的熟人和探究线索中接触到的人。
接触NPC：接触NPC后交谈并做出选择，一种是自己结识熟客，交谈甚欢。另一种是爷爷熟知的人来光顾，然后聊天触发好感，凭借爷爷的笔记要答出一些关键问题，然后与NPC搭线并且获得好感。并且会有夜晚茶馆夜宵摊的场景，可以在这些场景中进行遇见，然后聊天交流一些，获得好感以及可能会出现事件邀约。
