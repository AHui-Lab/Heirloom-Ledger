## P0：会决定长线骨架

### 当前：《万灯归舟》具体审阅项

用户已明确要求高价值核心藏品、虚构南迁故事、虚构声明、完整主线和互相关联的人物任务。以下是 [[WANDENG_STORY]] 已给出具体答案、但尚未人工定稿的设计选择，不是正文尚未写出的剧情空白。

- [ ] **WD-001 / 主物**：审阅《万灯归舟图》原卷、顾砚舟摹卷与《同舟航簿》三对象是否足以承载全篇；本版不再以茶罐为核心。
- [ ] **WD-002 / 爷爷责任尺度**：审阅“1998 年暂存、2002 年错误回信、2016 年实际交付”的具体真相，是否保留主动错误陈述的程度。
- [ ] **WD-003 / 玩家背景**：审阅固定文化项目内容统筹经历和未充分核验宣传的职责，是否适合玩家自定义范围；不预设玩家现在的道德态度。
- [ ] **WD-004 / 主对立与规模**：审阅梁绍钧从被误导收藏者转为限制公开范围的出资人是否足够有张力；本版条件报价 4,000 万/3,200 万仅属虚构叙事，不进入经济系统。
- [ ] **WD-005 / 篇幅与结局**：审阅六章、24 主线、12 支线、四种主结局的内容规模；职业尾声不将离开与道德失败绑定。
- [ ] **WD-006 / 世界与同步**：确定具体游戏年代、江城地域和原卷视觉形制；全篇定稿后同步愿景、旧第一章规格及人物资料，进入代码/数据仍需后续明确任务。

### 长期问题

以下保留既有产品层问题。《万灯归舟》已在方案内部给出全篇终章和主物形态等答案；不将这些旧问题视作暂停当前创作的前置审批。

- [ ] 整部作品是否有明确终章，还是采用可以长期经营、阶段性收束的结构？
- [ ] 玩家最终必须回答的核心问题是什么：是否留下经营、怎样经营、如何理解爷爷，还是三者的组合？
- [ ] 爷爷留下的“物品”是单一重要器物、一组互相关联的器物，还是对玩家人生方向的比喻性目标？现有愿景写有“找到爷爷留下的物品”，但具体形态未定。
- [ ] 爷爷一生中最重要的未竟之事是什么？它与第一章手续疏漏是同类问题、早期侧影，还是无直接关系？
- [ ] 第一章之后的长期对立压力主要来自市场竞争、行业规则、家族旧事、城市变迁，还是多线并行？

- [ ] 整体叙事视角采用第二人称、第一人称记录，还是分场景组合？
- [ ] 浪漫、宏伟、幽默三种调性的目标比例是否需要按主线/经营/夜间场景分别设定？

## 已采用但未锁定的方向

- 第一章采用现实底色的行业人情与家族旧事。
- 爷爷可以有误判、难处与未完成手续，不是全知谜题设计者。
- 序章、旧信、照片、调查疑问板已经进入沉浸式原型。
- 文风目标采用克制浪漫、由小见大的宏伟与人物化幽默，详见 [[NARRATIVE_STYLE_GUIDE]]。
