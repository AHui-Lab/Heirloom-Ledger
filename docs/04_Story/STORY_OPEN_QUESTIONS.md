# 剧情待决问题

本页只收纳会显著改变故事方向、人物关系或任务结构的问题。系统数值与公式继续记录在 [[OPEN_QUESTIONS]]。未确认的问题不得由 Agent、原型数据或 LLM 自动定案。

## P0：会决定长线骨架

- [ ] 整部作品是否有明确终章，还是采用可以长期经营、阶段性收束的结构？
- [ ] 玩家最终必须回答的核心问题是什么：是否留下经营、怎样经营、如何理解爷爷，还是三者的组合？
- [ ] 爷爷留下的“物品”是单一重要器物、一组互相关联的器物，还是对玩家人生方向的比喻性目标？现有愿景写有“找到爷爷留下的物品”，但具体形态未定。
- [ ] 爷爷一生中最重要的未竟之事是什么？它与第一章手续疏漏是同类问题、早期侧影，还是无直接关系？
- [ ] 第一章之后的长期对立压力主要来自市场竞争、行业规则、家族旧事、城市变迁，还是多线并行？

## P1：会决定人物与篇章节奏

- [ ] 第一章八名 NPC 中，哪些是长期核心角色，哪些以阶段性回归为主？
- [ ] 是否存在爱情线？如果存在，它是可选内容还是主线组成，是否允许无恋爱结局？
- [ ] 玩家背景的可定义范围有多大；过去职业是否固定，是否影响台词与任务入口？
- [ ] X City 的正式名称、地域气质、近现代历史与古玩行业生态是什么？
- [ ] 主线与动态经营故事的目标比例是多少？一个章节最多允许连续多少个纯经营日？
- [ ] 章节是固定顺序、条件解锁，还是允许若干篇章并行？
- [ ] 店外市场、茶馆、专家拜访与拍卖是正式故事结构，还是仅属于当前原型试验？

## P1：第一章必须澄清

- [ ] `catalogue` 疑问的显示条件与节点完成条件是否刻意不同？见 [[CH01_OLD_DEBTS#Q-CH01-001：`catalogue` 前置条件不一致]]。
- [ ] `photo.dismiss`、`custody.rush` 与 `stub.hide` 各自关闭什么路线，是否存在替代证据？
- [ ] 玩家多次选择“稍后”后，第一章能否自然超过十个营业日？节点怎样重新出现？
- [ ] 第一章三种收束之后，哪些具体人物记忆、物件状态与公开说法应带入下一章？
- [ ] “何景明清单混入一件后配物”具体对应哪件章节物品；现有文字提到罐盖，但跨文档对象标识需要统一。

## P2：创作策略

- [ ] 整体叙事视角采用第二人称、第一人称记录，还是分场景组合？
- [ ] 浪漫、宏伟、幽默三种调性的目标比例是否需要按主线/经营/夜间场景分别设定？
- [ ] 爷爷是否拥有可阅读的连续笔记，还是只留下零散账页、批注和未寄出信件？
- [ ] 是否允许超自然或“器物记忆”式表现？当前世界基调更接近现实主义，未确认前不得引入权威超自然事实。
- [ ] 玩家是否能为店铺、账本章节或自己的收藏命名？这些命名是否进入 NPC 表达？

## 已采用但未锁定的方向

- 第一章采用现实底色的行业人情与家族旧事。
- 爷爷可以有误判、难处与未完成手续，不是全知谜题设计者。
- 序章、旧信、照片、调查疑问板已经进入沉浸式原型。
- 文风目标采用克制浪漫、由小见大的宏伟与人物化幽默，详见 [[NARRATIVE_STYLE_GUIDE]]。
