# 人物弧与关系网

## 1. 人物弧原则

人物不是任务发放器，也不是某项系统数值的人形按钮。重要 NPC 的持续性来自四层并存：

1. **稳定内核**：身份、能力范围、性格、长期目标与不可轻易跨越的立场。
2. **当前处境**：眼下想解决什么，为什么现在来到店里。
3. **具体记忆**：玩家说过什么、承诺过什么、做成或做坏过什么。
4. **关系阶段**：防备、生疏、熟悉、信任、深交；它概括态度，但不覆盖前三层。

## 2. 玩家人物弧

### 已确认起点

- 长期在大城市工作，早年离乡，与爷爷接触不多。
- 在裁员和长期高压生活之后回到 X City，暂时接手古玩店。
- 从行业新人开始，必须在不完整信息中学习判断并承担风险。

### Draft Arc

```text
“我只是暂时回来”
→ “我在替爷爷收拾残局”
→ “别人开始因我的选择认识我”
→ “我可以理解爷爷，但不必复制爷爷”
→ “这本新账由我署名”
```

玩家性格不应被旁白写死。内在弧通过可选择的行动和克制的内心观察体现，不替玩家宣布“你终于原谅了爷爷”之类的情绪结论。

## 3. 爷爷：缺席的中心

爷爷的弧不是生者意义上的成长，而是玩家对他的理解逐层变化：

```text
遗产的主人
→ 别人口中的老掌柜
→ 有方法、有信誉也有疏漏的从业者
→ 作过艰难选择并留下后果的人
→ 玩家可以理解、质疑、继承或修正的一生
```

爷爷完整传记仍未确定。任何新章节只能揭示与当章证据直接相关的一面，不一次性补全他的全部秘密。

## 4. 第一章人物群像

下表的“现有事实”来自第一章规格与内容数据；“可发展张力”是 Draft，不代表已确定后续剧情。

| 人物 | 现有事实与稳定立场 | 第一章功能 | 可发展张力（Draft） | 幽默温度 |
|---|---|---|---|---|
| 赵庆生 | 修缮旧宅的街坊；好面子，真心相信家传物件值钱 | 展示“错误说法不必然等于欺骗” | 能否在被纠正后保住体面，又学会说“不知道” | 认真讲祖传，细问只传到他这一代的上个月 |
| 林若岚 | 为懂行长辈挑礼物；来源完整比夸张年代重要 | 检验玩家怎样说明库存 | 玩家是否把“体面”理解为名头，还是可交代 | 礼貌到让夸张推销自己显得尴尬 |
| 孙玉梅 | 茶庄后人；珍惜父亲生活痕迹，不愿把家事全算成钱 | 旧物原主意愿与情感价值 | 整理遗物既是放下，也是决定留下些什么 | 直爽拆穿把每只茶罐都叫“重器”的毛病 |
| 吴致远 | 年轻设计师；重尺寸、气韵和用途，不迷信名家 | 让器物作为生活之物而非只有投资属性 | 新收藏者如何形成自己的眼光 | 对术语不买账，却会认真量书架宽度 |
| 周伯安 | 爷爷老同行；重凭据，不替未核实结论背书 | 经手人、存根与行业旧规 | 他记得多少、愿承担多少、为何当年没补完手续 | 慢条斯理地让一句“差不多”无处藏身 |
| 许闻溪 | 器物修护师；先讲观察，再讲推测；专业非万能 | 比对旧照与后配物，校准证据边界 | 修护是恢复原貌，还是诚实保存变化 | 能用一句平静的“先翻过来”终止半桌宏论 |
| 何景明 | 经纪人；圆滑、有效率，倾向手续边谈边补 | 提供诱人的快速成交方案 | 效率何时是能力，何时把风险留给别人 | 每句“好说”后面都需要一张附表 |
| 陈素琴 | 小拍征集负责人；授权与说明优先于成交 | 将私人纠葛推向公开图录责任 | 市场机构如何在成交压力下守住表达边界 | 最有杀伤力的话往往是“这句依据在哪里” |

幽默温度栏只规定喜剧来源，不是可直接复制的固定台词。

## 5. 第一章关系网

```text
孙玉梅 / 孙家 —— 原主意愿、家庭记忆 —— 茶庄旧物
        │                                  │
        └── 周伯安 —— 当年经手、交接存根 ──┘
                 │
              爷爷 / 旧店
                 │
               玩家
        ┌────────┼─────────┐
     何景明    许闻溪      陈素琴
   推动流通    核对物件    核对授权与公开说明
```

- 周伯安不是原主；他的签名只证明经手。
- 孙玉梅的记忆与照片提供方向，但照片不能单独证明整批物权。
- 何景明不是自动的反派，他代表“先促成流通、手续后补”的行业诱惑。
- 许闻溪能说明观察与修护差异，不是所有类别的真相机器。
- 陈素琴负责公开说明与委托边界，不因为爷爷名声而省略核对。

## 6. 人物知情边界

每名重要 NPC 的剧情资料应单独列出：

- `personally_witnessed`：本人亲历；
- `told_by`：由谁告知；
- `publicly_known`：已传播到其所在圈层；
- `believes`：相信但未必为真；
- `suspects`：怀疑但不能断言；
- `will_not_share_yet`：知道但基于合理动机暂不说；
- `cannot_know`：当前绝不应知道。

LLM 只能在这些边界内组织台词。关系提升可以改变分享意愿，不能把 `cannot_know` 变成突然知道。

## 7. 人物成长检查

一条人物线进入制作前，应能回答：

- 此人想从玩家处得到的，除了钱还有什么？
- 他最怕被怎样误解？
- 哪项立场即使“深交”也不会自动放弃？
- 玩家哪项具体行为会被他记住？
- 他对玩家的变化表现在哪个行为，而不只是一句更亲热的台词？
- 如果玩家不推进其剧情，他是否仍像一个有日常的人？
