# 叙事文风规范

## 1. 总体调性

目标不是“每句话都华丽”，而是让朴素生活偶尔显出浪漫，让具体选择逐渐获得宏伟分量，让幽默像茶盖碰杯沿一样轻轻一响。

> [!summary] 风格公式
> **现实可信的行业人情 + 克制的诗意意象 + 从小事长出的史诗感 + 不伤人物尊严的幽默。**

## 2. 三种气质怎样使用

### 浪漫

- 写触感、气味、光线、旧痕和人与物的陪伴，不把“古老”自动写成“神秘”。
- 浪漫来自被认真保存的普通生活：茶罐上的手泽、收据上的折痕、旧照里没看镜头的人。
- 每段最多保留一个主意象，避免句句堆砌月色、尘埃与命运。

### 宏伟

- 用选择的后果与时间跨度制造分量，而非用夸张形容词。
- 从柜台尺度向外扩展：一笔记录如何影响一个家庭、一条街、一种行业评价。
- 宏伟场面仍需落在具体物与具体动作上。

### 幽默

- 优先采用性格碰撞、行业习惯、过分认真和生活窘迫。
- 不用网络梗破坏时代与世界质感，不让所有人共享同一种贫嘴。
- 不拿丧亲、贫困、被骗、物权争议和真诚无知作为笑柄。
- 笑点之后人物仍有尊严，重要场景仍保留余韵。

## 3. 四种文本声部

| 声部 | 功能 | 句法与长度 | 禁止事项 |
|---|---|---|---|
| NPC 对话 | 暴露立场、认知、保留与反应 | 口语化；一句通常只完成一个意图 | 替 Game Core 宣布真相；说出未知信息 |
| 玩家内心 | 整理已授权观察与不确定性 | 短、具体、留判断空间 | 替玩家决定情绪或道德立场 |
| 旁白 | 连接场景、时间与意象 | 克制；重点场景才放长句 | 把后台状态写成上帝视角答案 |
| 记录文本 | 账本、存根、事实卡、清单 | 准确、可核对、少修辞 | 用诗意模糊关键数字、授权或物权 |

同一条信息不要在四个声部中重复朗读。记录负责准确，人物负责态度，旁白负责空气，内心负责暂时的判断。

## 4. 场景节奏

### 开场

用一个感官细节、一个经营事实、一个尚未回答的问题。不要用大段世界观说明。

示例：

> 门锁比记忆里涩。你把“今日营业”翻到正面，柜台上的旧账却还停在没有价格的那一行。

### 交谈

每轮优先推进一种东西：信息、关系、交易或气氛。NPC 不需要每句都“有用”，但闲谈也应体现人物如何生活和看世界。

### 选择前

明确玩家已经知道什么、仍不知道什么、眼下决定会作用于什么；不暗示唯一正确答案。

### 结算后

先给准确结果，再给一小段余韵。钱要算清，诗意不能拿来藏账。

## 5. 第一章角色口吻

| 人物 | 语言节奏 | 常用关注点 | 避免 |
|---|---|---|---|
| 赵庆生 | 犹豫后补充，怕显得不懂 | 家里怎么说、东西放了多久 | 故意撒谎式奸笑 |
| 林若岚 | 礼貌追问，句子清楚 | 送谁、怎样说明、是否稳妥 | 只会谈预算 |
| 孙玉梅 | 直来直去，落在生活细节 | 父亲怎样用、自己想留什么 | 把哀伤写成持续哭诉 |
| 吴致远 | 简洁，偏视觉与使用感 | 尺寸、气韵、书房是否合适 | 突然变成行家背术语 |
| 周伯安 | 慢，常把词义拆清 | 谁经手、哪张纸、何时记下 | 神秘兮兮吊胃口 |
| 许闻溪 | 先观察、后边界 | 看见什么、不能推出什么 | 万能鉴定、绝对断言 |
| 何景明 | 顺滑、留余地、推进成交 | 行情、效率、以后来往 | 脸谱化反派威胁 |
| 陈素琴 | 正式、精准、少废话 | 授权、依据、公开文字 | 冷酷官僚腔 |

## 6. 幽默的角色分配

- 赵庆生：体面与常识的小小错位。
- 林若岚：过度礼貌使夸张推销自行破功。
- 孙玉梅：生活经验对行业大词的直接拆解。
- 吴致远：审美热情与现实尺寸、预算的碰撞。
- 周伯安：用极慢的速度纠正极含糊的话。
- 许闻溪：克制到近乎冷面笑匠，但不刻薄。
- 何景明：把复杂风险说得异常轻巧。
- 陈素琴：一条精确问题终结一段漂亮空话。

## 7. 语言检查清单

- [ ] 删掉不提供新意象或新信息的形容词。
- [ ] 一个角色的台词遮住姓名后，仍能大致认出是谁。
- [ ] 角色的知识没有越过其亲历、听闻与已传播范围。
- [ ] 鉴定结论保留证据边界，不把概率写成保证。
- [ ] 玩家内心没有擅自宣布爱、恨、原谅或决心。
- [ ] 幽默没有伤害弱势人物或毁掉情绪落点。
- [ ] 关键交易、授权、物权和结算用准确语言表达。
- [ ] 结尾留下回响，而非每次用格言替玩家总结。

## 8. 禁用倾向

- “冥冥之中，一切早已注定”式命定论。
- 所有老人都说古雅谜语，所有年轻人都说网络流行语。
- 为显宏伟而滥用“时代洪流、命运齿轮、历史长河”。
- 为显文艺而让人物在议价时突然朗诵散文。
- 每个事件都藏惊天秘密、每件器物都价值连城。
- 让爷爷笔记直接给出答案，玩家只负责翻页。

## 9. 与生成式对白的关系

本规范约束表达，不授权事实。给 LLM 的最小内容包应包含：当前说话人、稳定口吻、当前目标、可用记忆、可说事实、不可说事实、交谈阶段与 Game Core 已结算结果。任何漂亮但越权的句子都应被丢弃或重写。
