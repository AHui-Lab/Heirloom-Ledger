# 万灯归舟·策划审阅与制作拆分

## 1. 本轮交付到什么深度

本轮是全篇叙事设计与任务网络，不是已经完成全部对白的剧本。[[WANDENG_STORY]] 固定本方案内的完整真相、六章剧情和四种主结局；[[WANDENG_CHARACTERS]] 固定角色诉求、知情边界与回响；[[WANDENG_QUESTS]] 给出 24 个主线、12 个支线、依赖图和关键分支规格。

后续修改以这条已写完整的故事为对象，不继续为每章保留一个没有剧情的功能槽位。

## 2. 可在 Obsidian 监督的阅读路径

| 想检查什么 | 打开哪一页 | 审阅焦点 |
|---|---|---|
| 故事是否吸引人 | [[WANDENG_STORY]] 第 1、5、7 节 | 能否记住想买画的人、拒绝卖的人、爷爷说错的那句话 |
| 真相是否自洽 | [[WANDENG_STORY]] 第 2、4 节 | 两卷不是同一件，1930 年代与爷爷年代分开，权益没有随持有自动变更 |
| 人物是否像人 | [[WANDENG_CHARACTERS]] | 即使玩家退出，各人仍有独立诉求；谁主动拒绝或改条件 |
| 是否能玩而非只阅读 | [[WANDENG_QUESTS]] 主支线表 | 每次行动取得什么权限、改变什么报价或关系 |
| 选择是否有代价 | [[WANDENG_QUESTS]] G01—G04 | 成交后不能随意拿回物件，退出报价不能自动恢复，支线不能刷出万能好结局 |
| 哪些仍待决定 | [[STORY_OPEN_QUESTIONS]] WD 编号 | 人工审阅具体方案，而非让执行端发明真相 |

## 3. 叙事与经营互相支撑

玩家主要身份仍是掌柜。调查依附于有价的古籍收购、授权委托、普通库存交易、专业服务和有明确交接条件的原卷交易。不是所有来客都来提供线索，普通生意必须有自身获利空间。

| 阶段 | 玩家眼前可实现的经营结果 | 与大主线的关系 |
|---|---|---|
| 第一章 | 航簿委托或代理服务完成，小额常规交易 | 建立不是只能靠继承物变现的收入路径 |
| 第二章 | 孙家普通旧物授权出售、设计师实际采购 | 家属从“卖尽或全留”转向具体挑选 |
| 第三章 | 已取得权限的资料整理/协调委托，正常鉴别生意 | 接触大金额，但原卷仍不进入玩家自有库存 |
| 第四章 | 持续营业、处理旧成交回访 | 揭示旧事不应让一章只有连续审问 |
| 第五章 | 有成本的经纪、保存与展示方案 | 已赚资金和合作关系拓宽选择，不直接购买别人的同意 |
| 第六章 | 符合条件的佣金/服务费结算、实际交接 | 成交收益与物价分开；尾声回到下一名普通客人 |

本版梁与独立买家的故事条件报价分别为 4,000 万元与 3,200 万元；在方案内保持一致，整体仍可随审阅调整。委托费率、研究费用、修护费用、经营资金与职业待遇留待数值设计，不把剧情意向直接转换为当前经济系统参数。

## 4. 分支范围与可负担的制作结构

采用“章节主干汇合、关键结果持续”的结构。M04 的三种交易状态在 M05 都能汇合，但航簿所有者、已读内容和可用副本不同；M16 的家庭谈判可以汇合到 M17，但授权立场不同；M21 决定物件去向，M24 只添加职业和人物尾声。

不为每种组合写一套新的六章。每个关键节点写共用场景与条件段，并单独维护需要改变的行动许可和后果。人物知情包从记录生成，不能把另一条路线的对白直接套来。

首轮场景拆分规模估计为主线每单元 2—4 个事件、支线每单元 1—3 个事件，约 60—132 个事件；此为文案工作量范围，不是游玩时长、日期配额或制作承诺。准确范围需在逐节点剧本拆分后更新。

| 情境 | 可走路径 | 必须保留的损失／未知 | 检查结果 |

## 6. 从设计到制作的顺序与验收门

| 工作包 | 输入 | 产出 | Acceptance Criteria |
|---|---|---|---|
| P1 剧情定稿审阅 | 本轮四份设计 | 对主物、双卷、爷爷错误和旧职业的明确修订记录 | 六章动机与结果相连，WD 待决项有回应；可直接修改本稿，无须先单独批准抽象计划 |
| P2 全章事件拆分 | 24 M / 12 S | 按 [[QUEST_TEMPLATE]] 编写具体事件卡 | 每个事件有前置、玩家已知、授权、选择、后果、容量和拒绝路线 |
| P3 第一章连续剧本 | M01—M04 与 S01/S02/S04/S07 | 可逐场阅读的第一章，包含直接/代理/退出三条主要线路 | 第一笔生意能闭合；结尾引出两卷；主角不能提前知道原卷现址 |
| P4 后五章连续剧本 | 完整后台真相与事件卡 | 每章主场景、条件对白及关键物件文本 | 所有揭示至少有提前埋设的合法线索；无万能遗书和无依据跳转 |
| P5 文案纸面走查 | 全部剧本与任务网 | 不做支线、拒绝、顺利成交、无成交等路线记录 | 不跨知情边界、不重复结算、不靠最后选择恢复失去机会 |
| P6 视听与素材规格 | 已确认事件与物件 | 原卷/摹卷/航簿视觉差异、人物口吻、音乐与画面需求单 | 每种差异有叙事用途；所有核心资产原创或另有使用依据 |
| P7 数据与实现任务 | 另行明确要求进入游戏制作 | 数据 schema、实现与自动化测试任务 | 遵守 locked 规则与 Game Core 权威；本轮不执行 |

## 7. 现有内容如何复用

| 现有内容 | 当前处理 | 新版对应 |
|---|---|---|
| 茶罐收购重构稿 | 保留为旧备选，停止作为当前主线 | 轻型交易仍可用于普通经营；不承载核心长篇 |
| 第一章暂存、旧照、存根 | 保留原型记录，未来重写时复用表现方式 | M01/M05/M07/M13，不机械沿用旧 node ID 与同一真相 |
| 孙玉梅等八名 NPC | 保留基本身份与口吻，补独立线路 | 人物文档明确新增经历 |
| 图录核对与后配差异 | 复用“观察与说明分开”的任务逻辑 | M09/M10/M19，物件由茶器改为原卷与摹卷时需新规格 |
| 十日原型节奏 | 仅保留为旧原型规模 | 六章按条件推进，不强行套十天 |
| 长线功能槽位 | 留作旧框架参考 | 当前六章具体情节取代“以后再设计某类章节” |
| 愿景中的理解爷爷良苦用心 | 标出需同步修订的措辞 | 理解初衷、承认责任、由玩家选择怎样继续 |

旧数据与新故事不会混用。新方案获得定稿并明确要求进入实现时，再建立有迁移说明的任务；旧档案页继续反映它原本记录的版本。

## 8. 本版质量门与剩余工作

- 主线不是茶罐换成昂贵画卷后原地不动：双卷误认影响收藏机构，旧项目连接玩家责任，资金和授权决定终局可行性。
- 家庭所有权、艺术身份、历史贡献、私人原谅四个问题分别结算。
- 三类商业伙伴不是同一个反派：何景明卖渠道，陈素琴守专业审查，梁绍钧同时拥有收藏热爱和机构利益。
- 故事闭合到明确物件去向和人物尾声；“未成交”也是已写好的结果。
- 剩余工作是逐事件对白、具体经济数字、视觉形制核验、完整尾声组合与人工审阅。不能将本轮规划标作已经完成全部生产剧本。
