# 剧情圣经

## 1. 故事的心脏

《Heirloom Ledger》讲的不是“一个年轻人继承了一屋宝贝”，而是“一个年轻人继承了一屋尚未说清的关系”。

器物不会开口，因此人人都替它说话：卖家说祖传，经纪人说有行情，专家说证据不足，家属说那是父亲用过的东西。玩家真正学习的，不只是辨认瓷、纸、铜与木，也是辨认一句话背后的知识、愿望、羞耻和利益。

> [!quote] 核心命题
> 价格回答“它现在值多少”；账本回答“它经过谁的手”；而故事要追问的是——当一件东西落到你手上，你准备怎样对待它曾经属于的人。

## 2. 核心母题

### 2.1 继承与保管

继承不自动等于拥有。玩家得到店、库存、名声与关系，也同时得到误会、承诺和未完成的责任。

### 2.2 价格与价值

市场价可以结算，情感价值、证据价值与名誉代价不能被一个数字代替。剧情应让“赚钱”成为正当但不总是充分的理由。

### 2.3 判断与谦逊

懂得更多，不是从此永远正确，而是更清楚自己凭什么判断、哪里仍不知道。失败可以带来知识，但不应被浪漫化为没有代价。

### 2.4 记忆与证据

记忆提供方向，证据约束结论。照片证明某件物曾出现过，不自动证明物权；签名证明有人经手，不自动证明他是主人。

### 2.5 离开与归来

玩家回到故乡，不是退回过去，而是在旧门槛上练习一种新的生活。宏伟感来自一个普通人逐渐有能力承担更大的判断，而不是突然被命运册封。

## 3. 情感承诺

玩家长期应获得四种交替出现的感受：

1. **好奇**：一句说法、一处磨痕或一页缺失记录打开疑问。
2. **亲近**：人物在反复往来中显出生活，而不是只作为任务发放器。
3. **分量**：交易与选择会在以后被人记住，甚至换一种面貌回来。
4. **余韵**：结算之后仍留一点未被数字吞没的东西——一件归还的旧物、一句没说完的话、一页被重新写清的账。

## 4. 世界的叙事尺度

故事从店铺柜台开始，逐步扩展到街巷、市场、收藏圈与城市记忆。扩张单位不是地图面积，而是玩家能够理解和承担的关系范围。

```text
一件物的细节
→ 一次交易中的人
→ 一段家庭或行业关系
→ 一条在市场中传播的说法
→ 一座城市如何保存、遗忘和改写自己的过去
```

后期即使拥有更宏大的事件，仍要能落回一个具体动作：签名、交付、拒绝、说明、保存或归还。

## 5. 事实分层

每个剧情节点必须分开记录以下内容：

| 层级 | 含义 | 谁可以改变 |
|---|---|---|
| 客观事实 | 真伪、年代、物权、真实经历、已发生交易 | 仅由设计数据与 Game Core 确定 |
| 角色认知 | 某人相信、误记或推测的内容 | 由预设背景与已发生事件更新 |
| 角色表述 | 某人此刻选择说出的内容 | LLM 可在授权范围内表达 |
| 玩家已知 | 玩家已经取得并可查阅的事实或说法 | Game Core 按节点解锁 |
| 公共认知 | 已传播到某个圈层的版本 | Game Core 按传播条件结算 |

人物说错不等于撒谎；人物说真话也不等于说了全部。叙事悬念应来自这些层级的合理差距，而不是临时改写真相。

## 6. 标准叙事语法

每条主要剧情建议具备六个零件：

```text
人：带着需求、顾虑和立场来到玩家面前
物：提供可观察但不自解释的证据
话：角色给出可能真诚、错误、保留或圆滑的说法
据：记录、比较、专业观察或后续流转验证说法
择：玩家决定相信、查证、交易、暂缓、拒绝或承担
响：结果在关系、经营或后续事件中产生回声
```

少一个零件可以成为轻量事件；缺少“据”和“择”的内容，不应伪装成判断任务。

## 7. 爷爷的书写原则

### 已确认方向

- 爷爷已经去世，通过店铺、笔记、旧账、器物和他人的记忆在场。
- 他有经验和人脉，但不是全知安排者。
- 他可能帮助过人，也可能留下误判、含糊和没有办完的手续。

### 创作红线

- 不把每个 NPC 都写成“爷爷早已安排好来考验玩家”。
- 不让一封遗书一次性解释完整人生。
- 不用“为了你好”自动免除爷爷行为造成的后果。
- 不把所有珍贵物件都归因于爷爷慧眼识宝。
- 不让怀念只靠角色反复夸赞爷爷；矛盾、失望与感激应能同时成立。

## 8. 戏剧冲突原则

- 冲突优先来自正当目标之间的不兼容：急需现金与手续完整、家属纪念与市场流通、行业效率与证据责任。
- 反派不是必需品。何景明的圆滑可以制造风险，但不能因为他推动成交就自动写成恶人。
- 真相不能只由关系等级购买。关系可以换来愿意交谈的机会，证据仍需取得。
- 选择必须有代价，但不能每次都把善意设计成经济惩罚、把赚钱设计成道德失败。
- 幽默用于显出人物生命力，不用于消解器物归属、欺骗或失去亲人的重量。

## 9. 叙事红线

- 不用无证据反转惩罚玩家。
- 不因玩家没有读心而强制失败。
- 不让 NPC 知道隐藏库存、未传播交易或玩家未说出口的判断。
- 不把现实鉴定常识写成“看见一个特征即可保证真伪”。
- 不硬编码大量一次性故事文本进 Game Core；内容应数据驱动。
- 不在未确认前写死 X City 正式名称、最终结局、爱情对象或爷爷完整传记。
