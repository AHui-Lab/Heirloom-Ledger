# Heirloom Ledger｜公开作品集包

这是从 Godot 第一章试玩原型整理出的公开展示包，适合放进个人作品集、简历附件或录制 60–90 秒项目介绍视频。

## 展示定位

> 一款发生在虚构城市的叙事型古玩店经营游戏：玩家接手爷爷留下的小店，在不完整信息中与人交谈、判断物件、承担交易结果，并从旧账、照片和来客记忆里逐步还原一段未完的关系。

当前版本是可玩的章节原型，不是最终商业版本。截图中的对白为本地测试替身；真实模型的长期稳定性、延迟和最终文案质量尚未作为作品集承诺。

## 文件

- `index.html`：单文件作品集页面，可直接双击打开或部署到静态网站。
- `Heirloom-Ledger-Demo.mp4`：1920×1080、30fps、75 秒横版招聘展示视频，可直接上传。
- `Heirloom-Ledger-VibeCoding-Social-9x16.mp4`：1080×1920、30fps、48 秒竖版试玩宣传视频，适合小红书、抖音和招聘网站移动端展示。
- `SOCIAL_UPLOAD_COPY.md`：竖版视频对应的发布标题、正文和话题标签。
- `PORTFOLIO_CASE_STUDY.md`：适合复制到简历、Notion、Behance 或个人网站的项目介绍稿。
- `VIDEO_DEMO_SCRIPT.md`：约 75 秒视频 demo 的镜头、字幕和旁白稿。
- `check-public-package.ps1`：公开包脱敏检查；只扫描本目录，不读取用户配置。
- `assets/`：5 张精选试玩截图，已从原型截图复制并按公开展示用途重新命名。

## 脱敏边界

公开包只复制展示所需的图片和文案，不复制原型代码、设计文档、测试脚本、保存文件、运行日志、API 配置、API Key、模型名、服务商地址、用户目录路径或真实联调记录。

故事发生在虚构城市，人物和事件为原创内容。截图保留游戏内的虚构角色名，是为了展示叙事界面；不包含现实人物、现实店铺或真实客户资料。

原型本体未被修改。需要继续试玩时，请使用仓库中的 `prototype/开始试玩.cmd`；需要对外分享时，只分享 `showcase/` 目录。

## 公开展示前检查

在本目录执行：

```powershell
& ./check-public-package.ps1
```

通过条件：页面与素材齐全，且公开包中没有常见密钥字段、授权头、Windows 用户路径、存档、日志和模型联调痕迹。

## 验收标准

- 页面可脱离 Godot 原型打开，图片与中文文案正常显示。
- 作品集叙述只使用设计文档和验收记录中已经验证的功能。
- 公开包不包含 API Key、请求头、个人路径、存档、日志或测试入口。
- 视频分镜能直接指导录屏，不把模拟对白误写成真实模型效果。
