# Heirloom Ledger｜75 秒作品介绍视频 demo

## 视频规格

- 时长：75 秒左右
- 画幅：16:9，建议 1920×1080
- 音乐：低音量、带木质和雨夜质感的环境音乐；不使用带版权不明的歌曲
- 旁白：中文，语速偏慢，像在介绍一个正在生长的作品
- 公开标注：片尾写明“Godot playable prototype｜dialogue shown with local test substitute”

## 录屏顺序

1. 先录店铺和开场对话，鼠标移动慢一点，让场景热点有时间被看见。
2. 录一次“查看物品资料 → 形成私人判断 → 整数报价 → 确认交割”。
3. 录古玩街总览和一张物件详情，不必完整走完外出流程。
4. 录夜间茶馆的一段关系对话，再打开调查笔记。
5. 最后录三种章节收束页面或静态标题卡，不展示设置页、配置页和运行日志。

## 剪辑提示

- 镜头之间用 6–10 帧的柔和叠化或纸页翻动音，不要使用快速故障转场。
- 对话文字只保留一到两轮，避免观众把注意力花在阅读整段对白上。
- 所有截图和录屏角落加小字：`Playable prototype / local test dialogue`。
- 片尾不要写“AI 自动生成世界”或“无限记忆”；当前能准确支持的说法是“数据驱动的章节原型，LLM 仅负责表达已有状态”。
