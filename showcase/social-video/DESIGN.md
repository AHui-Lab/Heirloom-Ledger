# Social Video Visual Identity

## Style Prompt

Vertical short-form creator case study for a Chinese narrative game prototype. Start with a direct, human hook about vibe coding, then reveal the game through warm dark-wood imagery, aged-paper typography, amber gold accents, and clear system labels. The pacing should feel calm but intentional: large readable captions for muted playback, short sections, and page-like transitions that make each development idea feel like a discovered note.

## Colors

- `#171512` — ink-black background
- `#282119` — dark wood panel
- `#c89f55` — antique gold accent
- `#e4c98f` — warm headline text
- `#d4c6ae` — readable body text

## Typography

- Story / hook voice: `Georgia, serif`
- Vibe coding / system labels: `Consolas, monospace`

## Motion

Use vertical reveals, restrained scale pushes on screenshots, and warm-gold page-turn wipes. Each scene must enter visibly. Keep the first frame high-contrast and the captions large enough for a phone screen.

## What NOT to Do

- Do not show API configuration, keys, logs, source code, or internal documents.
- Do not claim the project is a finished commercial game.
- Do not describe local test dialogue as final AI output.
- Do not use unreadably small captions, glitch effects, or generic tech-neon styling.
