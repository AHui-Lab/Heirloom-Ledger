# 上传建议

把 `Heirloom-Ledger-Demo.mp4` 作为招聘网站的作品视频上传。文件为 1920×1080、30fps、75 秒、约 10.6 MB，画面内已包含项目名称、玩法说明、功能切片和原型状态标注。

如果招聘网站支持竖版视频，或你要同步发布到小红书 / 抖音，上传 `Heirloom-Ledger-VibeCoding-Social-9x16.mp4`。文件为 1080×1920、30fps、48 秒，采用真实原型画面、鼠标移动、点击反馈、输入流式文字和 NPC 回复流式展示；视频为静音字幕版，可在平台内添加音乐。

## 项目简介（可直接粘贴）

> Heirloom Ledger｜藏珍账是一款叙事型古玩店经营游戏原型。玩家通过与客人交谈、鉴定物件、议价交易和调查旧账，在不完整信息中作出判断并承担后果。项目使用 Godot 制作第一章可玩原型，包含 10 个章节化营业日、8 名重复来访 NPC、28 件器物数据，以及古玩街、专家拜访、拍卖和跨日调查记录。

## 想展示完整作品集时

## 作品状态说明

这是可玩的第一章原型，不是最终商业版本。视频中的对白使用本地测试替身；视频展示的是已验证的界面结构、数据驱动章节和经营流程，不把模拟对白包装成最终模型效果。
